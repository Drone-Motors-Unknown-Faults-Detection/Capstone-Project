## 1. 專題在解決什麼

### 1.1 一句話與完整問題

**本專題研究：在故障資料不完整時，能否先用健康資料建立馬達監測基準，發現超出已知範圍的訊號，收集相似樣本，再經人員確認更新模型。**

一般分類器像一張只有固定選項的考卷。若只學過健康、配置甲與配置乙，看到訓練時沒出現的配置丙，仍會挑一個舊選項。它可能答得很有信心，卻沒有「這題不在我會的範圍」這個出口。開放集診斷要增加這個出口：先判斷樣本是否與已知參考相容，再決定是否給類別答案。

設備剛導入時通常比較容易取得健康運轉資料，很難先取得每一種故障、每一種嚴重度與每一種工況的完整樣本。主線因此可以從健康開始，先回答「是否偏離這個健康基準」，暫時不要求辨識全部故障原因。這是單類監測的動機，不代表少量健康資料就足以辨識任意未知故障。

使用者可把系統想成研究與檢查輔助工具：輸入是既有量測轉成的特徵窗，輸出有開集分數、接受／未知判斷、已知配置、候選群組、趨勢與相對健康資訊。人員仍負責確認候選的意義；密度相近的一群，可能來自同一配置，也可能是工況改變、感測器異常或混合來源。[主線監測器][m-monitor]、[更新 session][m-exp2]。

### 1.2 五種容易混在一起的說法

「設備故障」是實體問題，例如固定件鬆動或零件失效；「訊號異常」只是量測偏離參考分布，兩者不能直接畫等號。轉速、負載、安裝與電流量測改變，也能造成訊號偏離。缺值、飽和、通道斷線等感測問題，甚至不能直接交給故障分類器當成正常輸入。

「已知故障」是模型已有標記參考的狀態；「未知」則是相對於這次已知集合而言，並不是固定的一種物理故障。冷啟動時只有 `8screws` 已知，其他配置都未知；確認 `7screws` 後，它成為已知故障，仍不是健康。模型的知識改變了，馬達沒有因此被修好。

現有資料以螺絲數量及位置配置命名。這些標籤能用來研究配置辨識，尚不足以說成九種不同物理故障原因。口頭報告應說「九種非健康配置」，不要把它們自動改稱軸承、繞組等九種病因。

### 1.3 目前完成到哪一層

目前是**離線研究加 CSV 逐窗回放的原型**，不是已接入飛行馬達的即時安全系統。Web 每秒送出幾筆，是播放與計算節奏，不是已驗證的感測採樣時鐘。人工安排的漸進／突發劇本，不是真實壽命試驗。[回放實作][m-live]。

同一工況各自建立健康基準時，既有資料中的健康與其他配置容易分開；跨馬達、多已知配置辨識卻有低召回與高誤報。這兩種結果可以同時成立，因為它們考的是不同問題。系統流程可運作，也不代表所有科學問題都已解決。

**可以這樣講給老師聽：**「我們先讓模型認識一顆馬達在某個轉速下的健康範圍。超出範圍先標未知，不強迫套成舊故障；相似未知累積後形成候選，再由人員確認。現在已能用既有資料展示這條流程，但還不能保證換一顆馬達就能沿用同一模型，也沒有實體壽命預測。」

**追問：未知是不是就一定危險？** 不是。未知只代表目前參考不足以解釋，應進一步檢查資料品質、工況及設備；它不能自行回答物理病因或危險等級。

## 2. Ancestor 與我們的工作

### 2.1 學長已經提供的基礎

Ancestor 封存沈品志、指導教授張淵仁的碩士研究《利用深度學習輔助式學習替診斷無人機馬達未知故障檢測》（逢甲大學航太與系統工程學系，2025 年 6 月）。可取得的是程式與論文 Markdown 轉錄；轉錄有 OCR 錯字、表格缺漏及敘述不一致，未取得原始 PDF 校訂。因此以下依程式描述實際流程，不把摘要中的百分比當成本次重新驗證。[論文轉錄][a-thesis]。

Ancestor 的 Step1 讀取感測檔、移除訊號離群點並切窗；Step2 把五通道轉成 105 維統計／倍頻特徵；Step3 使用健康及四種已知配置訓練 CNN、ResNet 類或 VGG 類模型，也有跨工況微調。Step4 從模型中間層取深層特徵，用 HDBSCAN 與馬氏距離判讀測試群；Step5 改變未知配置組合再測；Step6 把十配置重新建立分類網路。它已包含未知偵測、分群與重新訓練的概念，不能簡化成「舊版只有分類」。[Ancestor 說明][a-readme]。

128 份 notebook 是重複工況與架構的程式集合，不是 128 顆馬達。Step3 有 45 份，Step4／5／6 各 27 份，另外兩份是 GPU 測試與 T1/T2/T3 健康指標。Model01–09 對應 T1、10–18 對應 T2、19–27 對應 T3；編號同時區分轉速與架構。`.keras` 的 A／B／C 名稱與資料 T 碼不能憑字面配對，須讀 notebook 的實際載入路徑。

### 2.2 兩條計算路線有何差別

Ancestor 的神經網路先學五類分類，再將中間層輸出當作另一種特徵。代表性 CNN 是四層 Conv1D、16 filters、三次池化、Flatten、Dense16、Dropout0.3、softmax；ResNet 類使用殘差區塊，VGG 類使用更多小卷積。這些不是 Lineage 新提出的架構。它們學到的是分類用表示，不保證未知在這個表示中一定遠離已知。

代表性 Step4 將已知深層特徵的 HDBSCAN inlier 合併，估計一個全域中心與共變異數，加入小對角 ridge 後取偽逆；訓練距離的 q95 當門檻。測試批次先分群，再看**群中心**是否超線。部分群名使用測試真值多數決。主線 Lineage 則可直接以 105 維特徵建立逐類分布，使用另外的已知校準資料定門檻，逐筆判定，再把高分未知送去分群。[代表 Step4][a-step4]、[主線距離][m-maha]。

學長的遷移路線有目標工況的有標籤資料微調，不等於「只看 A 馬達就直接辨識 B 馬達」。Step6 代表程式重新建立十類 CNN，也不是只用最新到達群在線增量更新。這些不同資料條件，不能只靠比較最後 accuracy 就判新舊誰強。[Step3 微調][a-transfer]、[Step6][a-retrain]。

## 3. 先懂概念與評估

### 3.1 一筆資料與一個模型是什麼

一個 sample 是一個供模型判斷的樣本；這裡通常是一窗訊號所算出的 105 個數字。feature 是其中一個數字，例如某軸的 RMS。label 是資料附的答案，class 是答案所屬類別。不能把 105 個特徵叫成 105 筆獨立資料，也不能把同一顆馬達的幾千個窗叫成幾千顆設備。

「建立模型」不必都是神經網路訓練。馬氏距離估計中心與共變異數；k-NN 保存參考窗並建立查詢結構；logistic regression 學分類權重；神經網路透過 loss 反覆更新很多權重。PCA 學投影方向，t-SNE 則為這次圖中樣本求低維位置，不能視為已建立可部署分類器。

score 是連續分數，threshold 是把分數轉成判斷的界線。主線正規化分數愈大愈陌生，`score > 1` 判未知，等於 1 仍接受。分數 2 並不等於故障機率 200%。每種原始分數單位不同，正規化是相對自己的校準線比較，不是把所有方法變成同一個機率。[偵測器工廠][m-openset]。

### 3.2 五項工作不能互相冒充

監督式分類必須有已知標籤，回答「是哪一類」；單類偵測只建一個參考狀態，回答「是否離開參考」；異常偵測泛指偏離常態；open set 在已知分類外保留拒絕出口；新群發現把拒絕樣本按幾何相似組群。持續更新再把已確認的標記加入，涉及資料可用時間與舊知識保留。

例如模型把 7screws 拒絕成未知，可能是正確偵測；但它還沒把 7screws 說成正確已知類，因此不是已完成配置分類。HDBSCAN 出一群也不等於學會，還需要確認標記、建立參考及另外評估。畫面出現健康指數又是另一層解釋，不會補足缺失的分類或壽命真值。

### 3.3 四種資料角色

train 建立模型參數；validation 比較方法、特徵與超參數；calibration 在模型固定後決定拒絕線或健康錨點；test 是所有選擇停止後評估。如果看 test 換特徵，test 已參與設計，不能再叫未見盲測。把 validation 和 calibration 共用也會讓同一批資料同時影響選法與門檻，須如實揭露。

seed 是隨機程序的起點，固定它有助重現同一次洗牌，但不是新的資料。fold 是不同的角色分配；三個 motor 循環當 train／cal／test，有三折，仍只有三顆馬達。故障組合改變的是哪些類別被認識，與樣本 train 比例不同。

discovery 是用來找未知群的到達資料；update 是已確認後允許更新的資料；展示播放還可能循環抽同一列。這些角色都要與 final test 分開，否則「剛剛看過，現在認得」不能當成沒看過的新資料能力。

### 3.4 指標究竟在算什麼

以未知為陽性：TP 是未知被拒絕、FN 是未知被接受、FP 是健康／已知被拒絕、TN 是健康／已知被接受。未知召回 `TP/(TP+FN)` 問抓到多少未知；precision `TP/(TP+FP)` 問被拒絕的有多少真的未知；F1 是 precision 與 recall 的調和平均。健康誤報率用健康窗作分母，不能與已知多類錯分率互換。

accuracy 是全部答對比例。若評估有 100 個健康與 900 個未知，全判未知也有 90% accuracy，但健康全部誤報；這是示意，不是本專題新實測。因此還看 balanced accuracy（各類召回等權平均）與 macro-F1（各類 F1 等權平均）。多類「fault accuracy」若排除 healthy，與含 healthy 的 known accuracy 分母不同。

AUROC 比較已知與未知分數的排序，約可理解為隨機取一個未知，其分數高於隨機已知的機會；0.5 附近表示排序接近無差別，低於 0.5 不應自動翻方向挑漂亮分數。AUROC 好仍可能在固定門檻嚴重誤報：兩群都在 1 以上，未知比健康更高，排序可以好，健康卻全被拒絕。exp10 正是不能只看 AUROC 的例子。

分群 purity 需要事後真值；全選容易的單一配置群可有高 purity，不能證所有未知都會被找到。發現延遲若用 tick 作單位，只是播放筆數。事件級召回與逐窗召回不同，短尖峰觸發一次錯警報也不能用窗數平均掩蓋。

平均與標準差還要知道平均了什麼。九工況等權平均，與把全部窗混算的加權結果不同；三 seed 的標準差反映切分，不是三次獨立採集的信賴區間。由 95% 到 98% 是增加 3 個百分點，不是增加 3% 的相對比例。

### 3.5 四種量尺各回答什麼

健康偏離問離最初健康參考多遠；未知程度問是否離開所有已知類；方向熟悉度問偏離方向是否像已確認配置；健康指數把分數映射成相對刻度。已知故障增加後未知分數可下降，健康偏離不必下降。因此「認得故障」與「設備修好」是不同事件。[幾何][m-geometry]、[健康指數][m-health]。

**示範重述：**「我們先用 train 建參考，再用獨立已知 cal 定線，test 才量化誤報和漏接。判未知、分群、認出配置與追蹤健康是不同輸出；我會同時報健康誤報與未知召回，不只報很高的 accuracy。」

**追問：為什麼不直接調線讓 test 最好？** 因為那已用答案設計判斷器；得到的是對這批 test 的適配，不是新資料驗收。可以把它標為探索性分析，但需要另一份未曝光資料再驗。

## 4. 資料代表什麼

### 4.1 馬達、轉速與配置

資料設計包含 T1／T2／T3 三顆不同馬達，各有 6000／8000／11000 rpm。T1 較新、T2／T3 曾使用的敘述不能代替完整個體序號與使用時數，更不能串成同一顆由新到壞的生命曲線。轉速是工況的一部分，真實負載與安裝條件缺完整來源時維持 UNKNOWN。[研究來源補述][research-provenance]。

健康配置為 8screws；其他為 1–7screws、3_14screws、4_146screws。後兩者是既有位置配置標記，不從檔名自行推導螺絲位置圖或物理機制。顯示名稱的「輕微／嚴重」是操作詮釋，不是量測的損傷百分比。

舊檔與模型很大，不隨目前 GitHub checkout 附上。`data` 是被忽略、供程式唯讀的外部來源；新 checkout 找不到 data，不表示研究從未使用真實資料。重現前必須取得相符的組內來源版本，不能用亂數替代正式結果。

### 4.2 從五條波形變成一列 105 維

五通道是三軸加速度、電流及溫差。原始程式以溫度 C 減室溫作 Delta_T。名目取樣率 10000 Hz、每窗 10000 點，所以未移除點且連續採集時相當於一秒；舊清理會各通道刪不同點，不能從常數直接推目前每列仍是同步一秒。[前處理][a-preprocess]。

一段波形先算 15 個統計量：RMS 看平方後的整體幅度；均值看偏移；std／variance 看波動；峰度、偏度看分布形狀；peak-to-peak 看最高最低差；crest、clearance、shape、impulse 指標比較峰值與平均幅度；再加 max、min、mean square、mean absolute amplitude 等。部分量相互相關，例如 RMS 平方與 mean square 重複表達能量，這也是共變異數估計要注意的原因。

振動每軸再取 1X–10X 倍頻附近的 FFT 峰值。FFT 把「隨時間怎麼晃」換成「哪些頻率晃得多」；rpm／60 是名目旋轉頻率，程式採 100／133／183 Hz，對各倍頻用 ±5、8、10、12、15 Hz 等指定頻帶取最大幅值。這是有限頻帶特徵，不是追蹤瞬時轉速的 order tracking，也不是頻帶積分能量。

| 欄位位置（由 1 起算） | 通道 | 組成 |
|---|---|---|
| 1–15 | Current | 15 統計量 |
| 16–40 | Vibration_X | 15 統計量＋10 倍頻峰值 |
| 41–65 | Vibration_Y | 同上 |
| 66–90 | Vibration_Z | 同上 |
| 91–105 | Delta_T | 15 統計量 |

`15×5 + 10×3 = 105`。研究用 75 維是只取三軸各 25 個振動特徵，不是新採集 75 通道。66 維、69 維、形狀／幅值視圖是研究分支的選取或轉換，須依候選定義看，不能套到主線既有模型。[Ancestor 特徵][a-features]、[主線 registry][m-schema]。

欄名也不保證物理語意。historical_clean_v1 的三個 current 小寫及 Y／Z FFT 的 X 後綴是舊程式命名；adapter_generated_v1 的後綴按軸命名。兩套完整順序可合法讀取，不能混搭、擅自排序或只憑名稱宣稱軸已校正。

### 4.3 檔案與來源鏈

```text
組內原始 archive／量測
  → Ancestor 清理與切窗（歷史）
  → Step-*/myfeature/{Motor}/{RPM}/{Config}/*_Group_feature_data_clean.csv
  → 欄位／品質驗證 → train、cal、test 角色 → 實驗／展示
```

正式物化器是封裝格式轉接：Stage1／3 複製既有 clean bytes；Stage2 將已封裝的五通道窗轉為特徵。Stage 編號不能只看成同一顆馬達的時間段。目前物化 manifest 為 v3，使用相對 output ID、archive SHA 與 output SHA；來源根保存在本機 sidecar。[物化器][m-formal]。

內容 SHA 像檔案內容的指紋，能辨認同檔或改動，不能證明訊號採集獨立。同樣內容複製到另一個資料夾仍是同來源；沒有完全重複列，也可能有重疊或相鄰窗。現行 source_content_v2 對相對 file ID＋實際 bytes SHA 的排序清冊作整體雜湊；舊的 size／mtime 指紋另保留明確 legacy 入口，不混成同一版。[來源程式][m-provenance]。

### 4.4 已知數量與未知層級

研究分支正式集合的記錄為九工況、十配置，共 90 CSV、28910 列有限值 105 維特徵，指紋 `c4145d6efcbf02d294e77e5d83fdab5636bba6d9a58b1707752dd34b836f0b2d`。主線歷史 exp6／exp8 記為 `81c9192476ecd1e23a17b3ed5a343dcd50cdc2e5b7e0cc5466e9162941898228`；指紋算法不同時，只憑字串不能判定底層數值相同或不同。[來源補述][research-provenance]、[歷史正式彙總][r-exp6]。

這些是指定產物的數量，不保證任何人的目前 data 目錄都是 90 檔。掃描器依實際檔案列工況；嚴格物化會因通道形狀不符拒絕，因此舊九工況結果也不等於最新入口已重新產生相同九工況 bytes。

目前仍缺完整 raw session、視窗起訖／步長、清理遮罩、量測單位、軸方向、負載與使用時間鏈。查核到特徵 ID 及預測來源是工程追溯；對採集獨立、物理同步與生命週期仍須另要證據。[獨立性稽核][research-independence]。

**口頭說法：**「一列是五通道波形轉成的 105 個摘要數字。三顆馬達、三轉速和十配置是資料設計，幾萬列不是幾萬台設備；T1 到 T3 也不是同一台的退化。檔案指紋能證內容沒換，不能證錄製沒有重疊。」

**追問：有 105 欄就能餵模型嗎？** 不行。每個位置有固定意義，交換欄位會讓同一個權重或距離讀到不同量；現在 loader 比對完整登錄欄序，不能只數欄位。

## 5. 資料處理與切分

### 5.1 歷史清理做了什麼，沒有做什麼

Ancestor 先自然排序並串接感測檔，逐通道用 IQR 刪離群點：Q1／Q3 是第 25／75 百分位，IQR=Q3−Q1；訊號保留在 `[Q1−3IQR,Q3+3IQR]`。每通道各自切 10000 點，尾端不足一窗不保留。通道獨立刪點後，同一序號不一定仍對應同一時間，後面裁到最短窗數也不能補回同步。[Step1][a-preprocess]。

Step2 計算特徵，刪缺值，再用每欄 1.5IQR 邊界清理；任何一維超界整列不留。此規則在整個配置上先計算，再有後續 train／cal／test，故測試分布已影響上游清理。主線 train-only scaler 不能倒轉這種依賴。[Step2][a-features]。

物化 Stage2 的正式轉接器拒絕空通道或五通道窗數／長度不同，不再裁短；特徵轉換後會處理非有限值並作既有 IQR clean。這是**建立衍生資料版本的歷史規則**。目前 loader 是另一道入口：它不再默默刪 NaN／Inf 列，而是整次載入拒絕。不能把兩道程序的行為混成「新 loader 會幫你清乾淨」。[物化][m-formal]、[載入][m-data]。

正式轉接器的 clearance_indicator 計算式與代表性 Ancestor 特徵程式並不完全一致，欄名相同不保證公式等價。本輪不修公式、不重產資料；研究已有來源差異紀錄，對跨版本比較保留限制。[特徵程式][a-features]、[來源差異][research-provenance]。

### 5.2 現行讀取順序

先掃描 Step／myfeature 下真正有 clean CSV 的工況，再依配置與檔名排序讀取。loader 檢查 UTF-8／BOM、CSV header、列寬、數值與有限性。只接受兩套完整 ordered 105 欄 schema；重複／缺／多／錯序欄、任意 f0…f104、NaN／Inf、非數值與空配置都拒絕，不重排、不清洗後偷偷續跑。[欄位 registry][m-schema]。

配置接受十個 canonical 名及 `1screw` alias；同工況兩個 alias 同時出現會拒絕，避免當兩類。一般 cold-start 允許只有健康，但會回報 coverage 不完整；正式 exp6 在完整模式另要求九工況且每工況十配置。格式、類別 coverage、工況數是三件事，不是同一個「通過」。

通過後同配置多檔串接成 pool，保留列順序與原 key。`audit` 的 rejected_rows 是已查明的違規數，不代表尚未讀到檔案的總量；discarded_rows=0 表示沒有清洗，不表示全部資料已被接受。這些是 PR #56 已合併的能力，與較早成果報告所述「只挑數值欄並刪非有限列」不同。

### 5.3 fit 與 transform 為什麼分開

不同特徵量級不同：電流、加速度峰值與峰度直接相加，數值大的量會支配歐氏距離。RobustScaler 用 train 每欄的中位數 m 與 IQR a，把新值轉為 `(x−m)/a`；scaler 對零尺度有內建保護。fit 學 m、a，transform 只套用已學值，不再讀新的 test 分布改尺度。

例如某欄 train 中位數 10、IQR 2，新值 14 轉成 2。若看到 test 後重算尺度，就把未來資訊帶入模型。所有 PCA、NCA、分類器與距離估計也應依其角色只用允許資料；理想規則與實際例外分開核對，不能只因管線名叫 train-only 就假定每層獨立。[監測器][m-monitor]。

### 5.4 同工況 60／20／20 的實際意義

`make_split(n,rng)` 先洗牌，train 取 `floor(0.6n)`，cal 取 `max(1,floor(0.2n))`，其餘 holdout。因此不是每個 n 都剛好 60／20／20。代表 T1／8000 rpm 的健康池 n=313：

| 角色 | 窗數 | 健康池 313 作分母 | 用途 |
|---|---:|---:|---|
| train | 187 | 59.74% | scaler、健康分布／鄰居 |
| calibration | 62 | 19.81% | 拒絕門檻 |
| holdout | 64 | 20.45% | 健康接受／誤報評估 |
| 九配置未知池 | 2736 | 不屬於健康切分分母 | 只評估未知，不是各留 20% |

最後評估有 64+2736=2800 窗，未知占 97.71%，因此總 accuracy 容易被未知大量答對拉高。不能把「全部未知拿來評估」寫成「全部資料按 60／20／20」。[代表正式 summary][r-exp6-run]。

主線沒有全域固定的另留 validation：多數實驗使用固定設定與 known calibration。若在這批結果上不斷選方法，那是研究探索，不是憑換 seed 產生新的 final test。個別實驗還有自己的資料例外，後文逐項交代。

|---|---:|---:|---:|---:|

### 5.6 發現、更新與展示的特殊風險

已知播放用 monitor holdout；未知播放可從整個配置池抽樣。CycleSampler 抽完索引會再洗牌循環，所以第 600 個 tick 可能不是第 600 個不同窗。確認新類後才對其完整池切 train／cal／holdout，日後 holdout 可能先前已進過隔離。這會讓「學會後表現」混有曾見資料，不能當嚴格線上測試。[資料抽樣][m-data]、[更新][m-exp2]。

arrival-only 的研究必須記錄到達 IDs、確認時點、允許 replay 與固定 test；oracle 則容許完整池，是另一個上界參考。二者不能混成同一種持續學習。在 Web 確認後 score 下降，只能先說模型增加了參考，不說設備恢復。

### 5.7 如何檢查獨立性

先查列級：同一 ID 不可同時 train 與 test，完全重複 bytes 應辨認；再查錄製群組：相鄰或重疊窗不可只靠洗牌分開；再查個體：新馬達要整顆留出；最後查時間：早期資料訓練，未來才驗證，且清理／選特徵不能看未來。每上一層需要更多來源證據，不能由下層通過推出上層。

現行 schema 保證格式、內容 SHA 保證檔案身分，兩者都不保證 raw/session 獨立。即使三顆輪流留出，重複看測試結果選方法仍使其成探索性。最終要宣稱泛化，需來源可驗證、未用於設計的新群組；未取得時就縮小結論。[來源契約][m-provenance]、[獨立性][research-independence]。

**口頭重述：**「60／20／20 是每個已知池的列級切分，不是所有實驗通用比例。跨馬達要先指定誰訓練、誰校準、誰測試；未知配置不參與初始基準。現在格式與內容可檢查，但原始窗同步、錄製群組及歷史曝光仍有限制。」

**追問：修正 split 後分數沒有提高，是不是沒用？** 不是。修正的是結論可解釋範圍，不保證數值增加；應比較 IDs、擬合來源與預測是否一致。合法程序得出低分，比混用資料得到高分更能指出真正瓶頸。

## 6. 模型與方法：從數字走到判斷

本章先教主線，再教研究分支。所有示意數字只是幫助理解，不是新增實驗。共用的規則是：**模型參數由允許的 train 建立，門檻由允許的 known calibration 決定，測試只評估。** 例外與歷史限制會明寫，不能用這句規則替實作背書。

### 6.1 馬氏距離：偏離「平常的變動方向」多少

直線距離只看座標差多少，忽略什麼變化原本就常見。假設兩個振動特徵平常一起升降，點 `(2,2)` 與 `(2,−2)` 到原點的直線距離一樣；前者沿著平常的共同變化，後者一升一降反而罕見。馬氏距離用參考資料的變異與相關方向，區分這兩種情況。

平均向量 μ 是各欄中心；共變異數 Σ 的對角線描述每欄變動量，非對角線描述兩欄是否一起改變。對新向量 x，先算偏差 δ=x−μ，再用 precision P=Σ⁻¹ 衡量：

`d(x)=sqrt(δᵀPδ)`。

ᵀ 表示轉置，乘積把各方向偏差合成一個非負數；在常變方向同樣偏差較不罕見，在很少變的方向偏差會被放大。若各欄已獨立、變異皆為 1，才退化成普通歐氏距離。只要單位與共變異數一致，距離是相對尺度，不能讀成幾 g 或幾安培的損傷。

本專案先 RobustScaler，再建立每個已知配置的分布；原始距離還要經校準才能拒絕未知。統計方法學到中心、precision 及門檻，不學卷積權重；每筆推論固定使用這些量，新增類別時則整組重擬合。主線同工況結果好，不代表它能跨另一顆馬達保持相同分布。[距離程式][m-maha]；原始概念為 P. C. Mahalanobis（1936），*On the generalised distance in statistics*，原刊 2(1):49–55，[原文重刊](https://link.springer.com/article/10.1007/s13171-019-00164-5)。

**口頭說法：**「我們量的不是單純離中心多遠，而是沿這顆馬達平常會怎麼變的方向，偏離得多不多。」**追問：為何高維會出問題？** 共變異數要估計很多欄位關係；樣本不足或特徵高度重複時，有些方向的變異估得接近零，取反矩陣會放大微小誤差，所以需要正則化估計。

### 6.2 legacy 全域共變異數：舊新對照的基準與陷阱

legacy 把所有已知配置合併成一個分布。若健康和故障本來形成幾團，一個大橢球會把團間空隙也包住；未知落在空隙時，可能看起來離全域中心不遠。另一個問題是用同批 train 的距離 q95 定線，資料既建立橢球又自己測它，容易樂觀。

實作是 train 均值、`np.cov`、加 `1e−6I`、偽逆與 train q95。ridge 是加在每個對角線的小量；偽逆能處理不可逆方向，不等於估計已準確。它不需要 unknown，也沒有使用傳入 cal 來定原始門檻。[legacy 實作][m-maha]。

目前還有介面限制：legacy 的唯一 distribution label 是 `−1`，但監測器把負標籤當 unknown。因此 `predict_known_class`／`classify` 會把 legacy 都當未知，不能公平比較多類分類；`summary` 按配置找 split 時也不適合這個全域標記。分數層的二元比較與歷史深層特徵實驗不等於都受這個分類缺陷影響，須看呼叫的是 score 還是 classify。

**口頭說法：**「legacy 是全域、訓練自定線的舊拒絕參考；它和新流程改了不只一個因素，而且目前類別介面不對等，所以不能拿巨大 F1 差值說 LW 單獨進步那麼多。」**追問：那為何保留？** 保留原始基準與失敗有利追溯；本輪不能偷偷修它再覆寫舊成績。

### 6.3 Ledoit–Wolf：把不穩定的橢球收得規整一點

105 維含許多相關統計量，有限 train 很難精確估每一對關係。LW 把經驗共變異數 S 與較規整的縮放單位矩陣混合：

`Σ_LW=(1−α)S+αmI`，`m=trace(S)/p`。

p 是特徵數，trace 是對角線總和，m 是平均變異；I 為單位矩陣，α 在 0 與 1 間。α 大會減少不確定的相關結構，降低極小特徵值造成的 precision 爆大；代價是可能抹掉有用的細節。α 由資料估計，不是本專題固定選 0.95；0.95 是另外的校準分位數。

本專題使用 sklearn `LedoitWolf(assume_centered=False)`，每類 train 各估中心與 precision，再用該類 cal 原始距離 q95。它避免了把多類混成一球，但每類仍需足夠代表性的 train。換馬達後中心或尺度改變，矩陣可逆也不能保證門檻可用。[實作][m-maha]。

歷史 18 深層模型的整套改版使開集 accuracy 約 95.09%→98.64%；其中還改逐類、inlier 與校準，不能把全部 3.55 百分點歸因 α。主線 healthy-only 的正式比較與 k-NN 幾乎持平，跨馬達研究仍有零召回。[歷史原結果][r-old-lw]、[正式彙總][r-exp6]、[固定跨馬達][research-fixed]。Olivier Ledoit、Michael Wolf（2004），*A well-conditioned estimator for large-dimensional covariance matrices*，Journal of Multivariate Analysis 88(2):365–411，[DOI][p-lw]。

**口頭說法：**「LW 讓共變異數比較不容易被少量資料估歪；它修的是距離量尺，校準修的是決策線，兩件事要分開。」**追問：為何不用 α=1？** 全部縮成球會放棄所有相關資訊；資料決定的收縮是偏差與估計變動的折衷，不是愈大一定愈好。

### 6.4 OAS：同樣收縮，估計收縮量的假設不同

OAS 也混合 S 與 mI，差別在 α 的解析估計，以接近 Gaussian 樣本下的共變異數均方誤差為動機。不能只因名字有「oracle」就把它叫使用未知答案；這裡仍只讀 known train。Gaussian 是理論模型，不是已確認每個馬達特徵都符合常態。

主線用 sklearn OAS 逐類建分布、獨立 cal q95；研究另有 pooled within-class residual OAS，兩者不是同一個模型。sklearn 1.7 的實作與原論文某小項有差異，故稱既有實作應用，不聲稱手工逐式重現。[程式][m-maha]、[官方 OAS](https://scikit-learn.org/1.7/modules/generated/sklearn.covariance.OAS.html)。

歷史 18 模型平均開集 accuracy 約 98.61%，接近 LW 98.64%；這個小差距不能證明所有情況都選 LW，也沒有跨馬達可靠性保證。[原結果][r-old-lw]。Yilun Chen、Ami Wiesel、Yonina C. Eldar、Alfred O. Hero III（2010），*Shrinkage Algorithms for MMSE Covariance Estimation*，IEEE TSP 58(10):5016–5029，[DOI][p-oas]。

**口頭說法：**「OAS 和 LW 都是收縮估計，但估計收縮量的推導不同；我們在相同設定比較結果，不因理論名稱先宣布誰贏。」**追問：為何還要 cal？** 共變異數估得較好，不會自己產生可用的未知界線，仍須看已知新窗的距離。

### 6.5 PCA＋MCD：用穩健子集估分布

若少數離群點把平均與共變異數拉歪，MCD 嘗試找一個共變異數行列式小的資料子集，從較集中部分建立穩健位置與散布。這不是所有故障資料都丟掉：它只在每個允許的 known train 類內估計，不讀 unknown 真值。

高維相對少樣本會使穩健估計困難，本實作先在全部 known train fit PCA 保留 95% variance，必要時再把維度限制在最小類樣本數減 2；cal 和 test 只 transform。之後逐類 `MinCovDet`、cal q95。factory 沒有把外層 seed 傳進這個估計器，其內部預設 random_state=42；外層 seed 改變 split，不表示 MCD 的所有隨機來源都隨之改變。[程式][m-maha]。

穩健子集可能把有意義的多峰邊緣排除，PCA 也可能刪掉區分未知的小變異方向。歷史本批 accuracy 約 92.27%、未知召回 91.92%，比 legacy 更差，因此沒有採為預設；這只能否定該設定優勢，不否定穩健統計全部用途。[原結果][r-old-lw]。FastMCD 的實作來源：Peter J. Rousseeuw、Katrien Van Driessen（1999），Technometrics 41(3):212–223，[DOI](https://doi.org/10.1080/00401706.1999.10485670)；MCD 概念更早，不稱 1999 最初提出。

**口頭說法：**「MCD 要抵抗離群點，但我們還加了 PCA，兩者一起改變參考幾何；這批未知抓得較差，所以保留負面結果。」**追問：穩健為何會輸？** 對污染穩健與對未知分離是不同目標，且子集、降維及小樣本都可能犧牲辨識資訊。

### 6.6 獨立校準與逐類正規化

模型固定後，將該類 cal 窗送進距離，取 q95 為 τ_c。新窗對每類得 `s_c=d_c/τ_c`，整體 `s=min_c s_c`；只要某一類能合理解釋就接受，全部超過 1 才未知。若某類原始距離 6、門檻 3，正規化是 2；另一類距離 8、門檻 10 是 0.8，最後接受第二類。這是示意，說明最近的**正規化**類不一定是原始距離最近類。

τ 接近零時程式以機器 epsilon 保護除法，不能據此保證極端資料有合理判斷。cal 每類缺資料會拒絕 fit，不借 unknown 補校準。confidence=0.95 是分位數設定，不是「這筆有 95% 正確率」；62 個 cal 的尾端很少，test 誤報可高於名目 5%。

收縮改 Σ，校準改 τ，逐類改參考集合；三者同時變動就不能作單因子因果解讀。調高 τ 通常減少拒絕，也可能漏更多未知；調低則相反。[工廠][m-openset]、[監測器][m-monitor]。

**口頭說法：**「先學距離，再用沒參與擬合的已知資料量出界線；每類距離除自己的界線，所以 1 才有一致的拒絕意義。」**追問：為何不是直接用卡方理論線？** 現有縮放、高維估計、非 Gaussian 與有限樣本未滿足直接套理論分布的條件，使用經驗校準並實測誤報較符合此管線。

### 6.7 Conformal 校準：把分數放回已知排名

研究分支另試 conformal：新分數若比大部分已知 cal 都高，給小 p-value。常見有限樣本寫法為 `p=(1+#{cal score≥new score})/(n_cal+1)`，分子加 1 避免零 p；以 p≤α 拒絕，α 試 0.01／0.05／0.10。它建立的是校準分數的排名，不另訓練分類網路。[研究校準實驗][research-cal-code]。

重要前提是 cal 與未來已知樣本具可交換性等條件。跨馬達分布不同、重疊窗或反覆選模，都不能直接套「distribution-free」字樣宣稱保證每台誤報≤α。主線預設仍是分位數，conformal 是另存消融，不是所有 Web 的現行決策法。原理參考 Angelopoulos、Bates（2023）的 conformal 教學，[作者原文](https://arxiv.org/abs/2107.07511)。

**口頭說法：**「Conformal 用已知校準的排名看新樣本是否少見，能明確描述假設與有限樣本規則，但跨馬達不符合假設時仍要實測。」**追問：能修好差的表示嗎？** 不能。健康與未知排序本來重疊，換排名門檻也不會憑空產生可分資訊。

### 6.8 k-NN 開集距離：看附近有沒有已知參考

k-NN 不先假定橢球形狀，而是保存 train 參考窗。新窗對每類找 k 個最近鄰，算平均歐氏距離 `a_c=(1/k)Σ||x−x_j||`，再除該類 cal 的 q95。k 預設 5，train 少於 5 時主線取有效 k=min(5,n_train)。s=min_c a_c/τ_c 大於 1 才拒絕。[逐類 k-NN][m-openset]。

例如附近五個參考距離為 1、1、2、2、4，平均是 2；該類 cal 線若為 2.5，分數 0.8。它會跟著資料的局部形狀，不需估完整共變異數；代價是要保存參考、查詢成本隨樣本增加，高維的距離集中與參考覆蓋不足仍會失效。k 小較受單點影響，k 大較平滑也可能跨過細群邊界。

正式 exp6 固定同 split／cal 比較時兩方法幾乎持平，不支持「不用共變異數就一定更好」。`core.detectors.KNNDistanceDet` 是 healthy-only 廣度候選、固定 k=5，與可多類的工廠不同。Cover、Hart（1967）的近鄰分類是重要來源，[DOI](https://doi.org/10.1109/TIT.1967.1053964)；本專題拒絕平均距離是工程組合，不直接套其 IID 分類誤差界。

**口頭說法：**「馬氏看一個估計分布，k-NN 看真實參考窗是否在附近；兩者都要另外校準拒絕線。」**追問：k-NN 沒訓練嗎？** 沒有梯度權重訓練，但有保存 train、建立鄰居索引及校準，仍有擬合來源與資料洩漏問題。

### 6.9 One-Class SVM：用核函數圍住已知支持區

OCSVM 在轉換後空間找包住已知資料支持區的邊界；RBF 核可表達非線性邊界，不必一個橢球。nu=0.05 控制訓練邊界相關的折衷，gamma=scale 依 train 尺度決定核寬，不等於未來健康誤報固定 5%。

廣度比較用健康 train fit，將 `−decision_function` 轉成愈大愈異常，再以 healthy cal q95 定線。若校準分數非正，基底 wrapper 先平移再正規化；這是程式數值約定，不是概率。研究全已知版本另取 `−score_samples`，不能混用原始值。[八法偵測器][m-detectors]。

本資料同工況九工況均能排序故障，但其他跨群組 P1 條件未知召回可低到零，說明彈性邊界也受 domain shift 影響。來源為 Schölkopf 等（2001），*Estimating the Support of a High-Dimensional Distribution*，Neural Computation 13:1443–1471，[DOI](https://doi.org/10.1162/089976601750264965)。

**口頭說法：**「它用核邊界描述已知支持範圍，再用獨立 cal 定拒絕；不是先用故障答案學二元分類。」**追問：邊界愈複雜愈好嗎？** 小樣本與新工況下可能更易貼合舊資料，仍須同角色對照。

### 6.10 Isolation Forest：容易被切得孤立的點較可疑

樹反覆隨機選欄位及切值，把資料分開。孤立點常較早落到單獨葉子，平均路徑較短；模型把它轉成異常分數。它建立多棵隨機分割樹，不學已知故障類別，也不使用群中心。

本專題廣度版固定 200 棵、random_state=seed，healthy train fit，取套件 `−score_samples`，healthy cal q95。研究全已知版另固定 max_samples=256、n_jobs=1。訓練參考若混入不同工況／已知故障，稀有但合法的區域也可能被隔離，所以換參考集合會改問題。[實作][m-detectors]、[研究 novelty][research-literature]。

同工況平均健康誤報約 8.44%，沒有在這批勝過 LW；不能從此說樹不適合所有 PHM。[原結果][r-broad]。Liu、Ting、Zhou（2008），*Isolation Forest*，ICDM:413–422，[作者原文](https://cs.nju.edu.cn/zhouzh/zhouzh.files/publication/icdm08b.pdf)。

**口頭說法：**「它問一筆資料在已知參考裡是否很容易被隨機切得孤立。」**追問：有 anomaly score 就不用 cal？** 不同資料的路徑分布不同，本比較仍用相同 known-cal 規則，不能直接把套件預設 contamination 當實測門檻。

### 6.11 LOF：比自己的鄰居稀疏嗎

LOF 比較一點周圍的局部密度和鄰居的密度。兩個本來密度不同的正常群，用全域距離可能誤判較鬆的一群；局部比較希望避免這種情況。但跨馬達整片移位、或新點附近沒有合適參考時，它仍可能失效。

廣度版 `LocalOutlierFactor(n_neighbors=20,novelty=True)` 只在 healthy train fit，對新的 cal／test 用 novelty 分數，取負後再校準；不是拿 fit 階段的 training outlier scores 當新樣本。主線 factory 沒有把 LOF 接成一般多類更新方法。[實作][m-detectors]。

同工況平均健康誤報約 6.67%，P1 跨群組的行為則明顯不同，不能跨設定排名。[原結果][r-broad]。Breunig、Kriegel、Ng、Sander（2000），*LOF: Identifying Density-Based Local Outliers*，SIGMOD:93–104，[DOI](https://doi.org/10.1145/342009.335388)。novelty=True 是既有實作對新樣本的延伸。

**口頭說法：**「它比較相對鄰居的密度，不只看離全域中心多遠。」**追問：是否等於 HDBSCAN？** 不等於。LOF 產生局部離群分數，HDBSCAN 產生群與噪聲，後者在此還要人工確認。

### 6.12 PCA：保留主要方向，或量重建不了的部分

PCA 在 train 中找變動最大的互相正交方向；它不讀 class labels。投影是 `z=Vᵀ(x−μ)`，V 是保留方向，μ 是 train 中心；重建 `x̂=μ+Vz`，誤差 `||x−x̂||` 表示落在被丟棄方向的程度。大變異不等於對故障最有用，故未知若沿保留方向走很遠仍可能重建得好。

廣度 PCA reconstruction 保留 95% variance，用 train fit、cal 重建誤差 q95；MCD 前 PCA 是為估計維度控制；監測器 PCA2 是只供畫面投影；研究 PCA10／20 是表示比較。這四個角色不能共用「PCA 表現」一個分數。PCA2 圖不是最終偵測空間，圖中靠近未必 105 維也近。[偵測器][m-detectors]、[監測器][m-monitor]。

同工況重建法平均健康誤報約 6.38%，不證明線性子空間能跨個體。[原結果][r-broad]。原始重要來源 Pearson（1901），*On lines and planes of closest fit to systems of points in space*，[DOI](https://doi.org/10.1080/14786440109462720)；本專題使用 sklearn PCA，而非重現該文的幾何案例。

**口頭說法：**「PCA 學的是主要變動方向；作偵測時看重建誤差，作畫圖時只降到二維，兩者不同。」**追問：95% variance 是 95% 準確率？** 不是，保留的是 train 的變異量，不是分類正確率或未知召回。

### 6.13 MLP AutoEncoder：健康訊號壓縮再還原

AE 要學 `x→f(x)→g(f(x))≈x`，中間較窄的 16 維迫使模型壓縮健康特徵；不熟悉的結構可能還原較差，重建誤差就大。它不需要故障 label，loss 是重建的平方誤差，不是已知故障 softmax。

本實作是 sklearn MLPRegressor，輸入與目標同為 scaler 後 X；隱藏 64／16／64、ReLU、輸出 105 維、max_iter=2000、early_stopping=True、random_state=seed。未明寫的設定沿 sklearn 1.7.2：Adam、初始步長 0.001、L2 alpha=0.0001、batch=min(200,n_samples)，train 內另留約 10% 做 early stopping，tol=0.0001、連續 10 輪無改善停止；最佳驗證權重由套件保留，沒有額外由 test 選 checkpoint。這個內部 validation 不是外層 calibration。[程式][m-detectors]、[固定版本 API](https://scikit-learn.org/1.7/modules/generated/sklearn.neural_network.MLPRegressor.html)。

推論取 `||x−MLP(x)||`，用外層健康 cal q95 拒絕。非線性可表達彎曲結構，也可能把未知一起重建好；不能只憑「深度」預期優勝。九工況 seed42 平均健康誤報 5.83%，較同批 LW 7.11% 低 1.28 百分點，未知排序與召回均已飽和；只有一 seed，沒有足夠跨馬達驗證。[同批結果][r-broad]。

Hinton、Salakhutdinov（2006），*Reducing the Dimensionality of Data with Neural Networks*，Science 313:504–507 是代表性 AE 文獻，[DOI](https://doi.org/10.1126/science.1127647)；這裡沒有複製該文深層預訓練，也不稱它是 AE 最初發明。

**口頭說法：**「我們只教網路還原健康特徵，再看新窗的重建誤差；內層早停和外層定線用不同資料。」**追問：為何沒換預設？** 單 seed 的小誤報差還不足以支持通用替換，且跨個體主要問題沒有因此解決。

### 6.14 HDBSCAN：在隔離區找密度穩定群

先懂密度：相似點擠在一起，孤立點較像噪聲。HDBSCAN 用近鄰相關的密度尺度建立層級群，找在不同密度門檻下較穩定的群，不必先指定一定有幾類；不夠群的點可留為 noise=−1。它的 −1 是分群噪聲，與偵測器 −1 的未知標籤是不同層。

主線先 score 拒絕，再把明顯超過隔離線 2 的窗縮放，對隔離集合 `fit_predict`。先試 min_cluster_size=25、min_samples=3；隔離≥75 加試 (15,3)，≥100 加試 (10,2)，但候選本身仍至少 25 窗。每 10 個新隔離窗才重試，取目前最大合格群，避免每筆重分群。mcs 是密度群建構參數，候選門檻則是後端接受規則，不是相同概念。[session][m-exp2]。

密度階梯讓發散配置較有機會被找到，也可能增加細群或噪聲候選，不能理論保證 purity 不變。分群幾何不讀 label，但程式建候選時已讀 truth 多數、purity、is_known；UI 延後顯示答案不表示後端直到確認才接觸真值。確認新配置還要標註與模型更新。

Campello、Moulavi、Sander（2013），*Density-Based Clustering Based on Hierarchical Density Estimates*，PAKDD:160–172，[DOI](https://doi.org/10.1007/978-3-642-37456-2_14)。Ancestor 已使用此類方法，專題新增的是隔離與確認編排。

**口頭說法：**「分群只提供值得檢查的相似群，不會自己知道故障原因；沒成群就繼續累積，不能因為湊到 25 就說一定發現。」**追問：purity=1 就代表成功？** 只證這個候選對已知真值一致，還需看未發現樣本、混群與更新後未見資料。

### 6.15 EWMA：追蹤最近未知比例

單一健康誤報不必立刻變成事件。每筆先轉成 b_t=1（score>1）或 0，再更新 `e_t=(1−α)e_(t−1)+αb_t`。α=0.08 表示新旗標占 8%、舊狀態占 92%，過去影響逐步衰減；它不是固定長度窗的單純平均。[趨勢程式][m-trend]。

本實作 reset 從 0 起，重新武裝後前 10 筆不警報，之後 e≥0.5 首次觸發；在最近 120 筆歷史中，數 e 落在 [0.2,0.5) 的筆數，不超過 12 判 sudden，否則 gradual。它判的是未知密度如何跨線，不直接分析軸承磨耗。換來源可 rearm，保留 t 但清統計，故不同段不能不看狀態直接比。

劇本 A／B 各 40 次的類型正確率 97.5%，支持人工注入模式的規則效果，不是現場磨損準確率。[40次結果][r-exp3]。Roberts（1959），*Control Chart Tests Based on Geometric Moving Averages*，Technometrics 1:239–250，[DOI](https://doi.org/10.1080/00401706.1959.10489860)；中間帶與停留規則是專題約定。

**口頭說法：**「EWMA 把最近異常比例平滑，連續異常會推高，比單點更像事件。」**追問：0.5 是故障機率 50%？** 不是，是指示值的平滑統計警報線，不是經校準的設備故障機率。

### 6.16 CUSUM：累積超過基準的正偏移

CUSUM 本版更新 `c_t=max(0,c_(t−1)+score_t−1)`。score=3 一筆加 2，score=0.8 減 0.2、最低為零；因此大幅偏離可很快推高。EWMA 用 0／1，CUSUM 保留分數幅度，兩者追蹤不同資訊。

在主線 CUSUM 供顯示，不是決定漸進／突發的正式觸發器；沒有本版為它另外校準每小時誤報的門檻。原始 Page（1954），*Continuous Inspection Schemes*，Biometrika 41:100–115，[DOI](https://doi.org/10.1093/biomet/41.1-2.100)。本專題使用簡化單邊累積，不能把原控制圖理論的平均警報長度直接套上。[程式][m-trend]。

**口頭說法：**「CUSUM 顯示累積了多少超線幅度，EWMA 顯示最近超線密度；現在類型判斷看的是 EWMA 停留。」**追問：一直累積就是持續磨損嗎？** 不一定，工況轉移或感測偏移也會持續高分，需來源與設備真值才能解釋。

### 6.17 PolarMap：健康白化後看方向與半徑

白化可想成把健康橢球旋轉、縮放成較規整的球。由健康 precision P_H 的 Cholesky 分解建立 W，得到 `z=W(x−μ_H)`；r=||z|| 是離健康中心的馬氏半徑。每個已知故障中心也轉到 z，除自身長度得到射線單位向量 u_c；`cos_c=(z/||z||)·u_c` 愈接近 1，方向愈像該配置。

程式用每類已知 **holdout** 方向相似度的低 5 百分位作 τ_c，因此這批 holdout 已參與方向校準，不能再稱獨立方向 final test。最佳 cos 達該射線門檻為 same_ray，否則 new_direction；severity=`r×best_cos/ray_radius` 是沿射線的相對投影，可負或大於 1，不是損傷比例。[幾何][m-geometry]。

即使 detector 選 k-NN，PolarMap 仍另 fit LW 幾何，不能把圖的馬氏半徑說成 k-NN 距離。每次加入類別會重建 scaler／geometry，健康錨點不保證跨模型版本數值完全固定；只有另項分數分離研究刻意凍結健康參考。只有健康時沒射線，方向回 new_direction、severity=None。

exp4 的方向效果對錨點差異很大：7screws 錨點的族群 AUROC 約 0.9968，1screws 則 0.1463。這說明幾何可以幫助解釋，但不能當已驗證病因分類器。[原結果][r-exp4]。此白化、射線與門檻是本專題的組合，不假稱一篇原論文已證明馬達星狀退化。

**口頭說法：**「半徑問偏離健康多遠，方向問像不像已知配置；學會新方向不等於回到健康中心。」**追問：same_ray 是否已知？** 不一定，開集拒絕與方向分析分開算；超線但方向熟悉可以是變體，仍需要確認。

### 6.18 Health Index：用已知校準定相對刻度

原始分數大小不方便讀，exp8 把 cal 分數低 q10 記為 a、高 q95 記為 b，映射 `HI=clip(1−(score−a)/(b−a),0,1)`。a 以下為 1，b 以上為 0，中間線性；b≤a 時程式加極小差保護。只有已知 cal 建錨點，不借 unknown 把圖拉得漂亮。[校準器][m-health-cal]。

`CalibratedHealthIndex.fit` 建 train-only scaler／detector，再以其 cal 分數建立映射。新樣本還輸出 degradation_score=1−HI、相對 severity 區間（0.8／0.5／0.2）、unknown／uncertain、confidence proxy。proxy=`|score−1|/(1+|score−1|)`，離線愈遠代理值愈大，不是分類機率；缺 taxonomy 時已知也只回 uncertain，不編物理原因。[指數與診斷][m-health]。

同工況 exp8 的健康平均 HI 約 0.58–0.60、未知為 0，代表與這份 cal 的位置關係，不表示健康馬達已損壞 40%。[原結果][r-exp8]。多已知配置的開集分數還會受熟悉度影響，所以不能把學新故障後 HI 上升解釋成實體恢復。RUL 保持 None／false，沒有由此計算壽命。

**口頭說法：**「健康指數是相對校準刻度，便於看分布與趨勢；0 不是壽命用完，1 也不是安全認證。」**追問：為何平均健康不接近 1？** 1 只給 cal 低分尾端附近，其餘健康依刻度分布在 0 到 1，不是用健康標籤強制全設 1。

### 6.19 Session 健康趨勢：平滑、遲滯與資料不足

另一套趨勢先取最近最多三筆 HI 中位數，抑制單窗尖峰，再 EWMA alpha=0.2。至少五筆後，以最多 120 筆平滑值對筆序作直線斜率，負斜率的相反數為 degradation_rate；大於 0.005 判 worsening，小於 −0.005 判 recovering，其餘 stable。單位是每筆，不是每小時，除非另有合格時間契約。[trajectory][m-trajectory]。

告警採低 HI：正常狀態持續三筆低於 0.5 可 warning、低於 0.2 可 critical；解除線分別 0.6／0.3，持續三筆。進入與解除不同稱遲滯，可避免在線附近來回閃爍。實際現況還有狀態限制：warning 分支只處理解除，沒有明確的 warning→critical 升級分支；不能把門檻表誤讀成任何狀態都能互轉。本輪只揭露，不修碼。

change point 比較前一次平滑值與目前 robust health 的下降是否≥0.15，連續兩次才 confirmed；不是以真實故障發生時刻監督訓練。狀態依 (motor_id,session_id) 分開，缺身分時回 insufficient_history／data_quality insufficient，不把不同馬達串成退化。畫面 recovering 也只表示相對刻度趨勢回升。

**口頭說法：**「我們先抑制短尖峰，再對同 session 累積趨勢與持續告警；缺身分就不假造歷史。」**追問：它跟 exp3 一樣嗎？** 不一樣。exp3 平滑未知旗標、alpha0.08，這套平滑 HI、alpha0.2，輸出與門檻不可混用。

### 6.20 Ancestor CNN：學局部特徵組合來分類

一維卷積以小權重窗沿 105 個特徵位置移動，抽出局部組合，再 ReLU 保留非線性反應；池化縮短位置、Flatten 攤平，Dense 組合成類別 logits，softmax 轉成各已知類相對分數。這裡沿的是人工排列的特徵位置，不是直接沿 raw 時間，不能稱 raw waveform end-to-end CNN。

代表模型輸入 (105,1)，四層 Conv1D 皆 16 filters／kernel3，首層 same，後三層接 pool2；Flatten 後 Dense16、Dropout0.3、Dense5 softmax。train_test_split 80／20、seed42、stratify label；RobustScaler fit train。loss 為 sparse categorical cross-entropy，Adam learning_rate=1e−4、batch32、最多100 epoch，val_loss 連續10輪無改善 EarlyStopping 並還原最佳權重。[CNN notebook][a-cnn]。

模型學卷積與分類權重；未知偵測另外取 Flatten 176 維。相同 20% X_test 又用於早停與最後評估，所以不是未參與模型選擇的 final test。closed-set softmax 全部總和為 1，陌生樣本仍可能高信心，需額外拒絕。

**口頭說法：**「CNN 在特徵序列上學組合，學會已知分類後取中間表示做未知偵測；分類高分不保證未知會離得遠。」**追問：原資料有幾類？** 代表 Step3 為健康加四配置五類，Step6 再建十類；不能把十類重訓說成 Step3 已知九故障。

### 6.21 Ancestor ResNet 類：殘差連接讓深層調整較容易

一般深網每層都改輸入，殘差區塊改成 `輸出=F(x)+shortcut(x)`：主分支學需要修正的部分，shortcut 保留直接路徑，維度或 stride 不同時用 1×1 卷積配齊。這能協助最佳化，不保證跨設備不變。

代表程式起始 Conv1D32／kernel7／stride2，BN、ReLU、pool3；四組各兩個 basic blocks，filters 32、32、64、128，部分首 block stride2。每 block 兩次 kernel3 加 BN，最後 GlobalAveragePooling 成128維、Dense5 softmax；loss、Adam1e−4、batch32、100epoch／早停10與前述相同。[ResNet notebook][a-resnet]。

GAP 平均各位置的通道反應，與 CNN Flatten 保留位置方式不同；不能只因 128 小於176就斷言少維一定比較差。深度殘差概念來源 He 等（2016），*Deep Residual Learning for Image Recognition*，[原刊](https://openaccess.thecvf.com/content_cvpr_2016/html/He_Deep_Residual_Learning_CVPR_2016_paper.html)；本專題為 1D 小 filters 改編，非原 ImageNet ResNet 完整複製。

**口頭說法：**「ResNet 讓深層學修正量，主要幫訓練，不自動解決健康與未知分離。」**追問：層數比較如何算？** Keras 計算圖還含 BN／Activation／Add，與只數加權層不同；應講實際 block，不拿不同口徑層數作優越證明。

### 6.22 Ancestor VGG 類：堆疊小卷積

VGG 類用多層 kernel3 增加可組合的局部模式，池化逐步縮短位置。代表 1D 版本有13個 Conv1D（各16 filters、same）、五次 pool2，再 Flatten、兩個 Dense16／Dropout0.3，最後五類 softmax；輸入105經五次池化剩3個位置，Flatten為48維。其他訓練設定同代表 CNN。[VGG notebook][a-vgg]。

它學較深的非線性表示，但目前特徵早已是摘要，不等於原作影像階層的資料條件。歷史比較有高閉集 accuracy，仍須另查距離分離；不能用網路名稱推測新馬達表現。概念來源 Simonyan、Zisserman（2015），*Very Deep Convolutional Networks for Large-Scale Image Recognition*，ICLR，[作者預印本](https://arxiv.org/abs/1409.1556)。

**口頭說法：**「我們比較的是小型一維 VGG 類表示，不是把原影像 VGG16 原封不動搬來。」**追問：48 維一定不好嗎？** 不一定；維度、訊號內容、正則化與校準互相影響，需要控制比較，不能從三架構相關就證維度因果。

### 6.23 有標籤微調與健康中心平移：兩種不同的轉移

Ancestor 微調載入來源 `.keras`，凍結約前半層，只更新其餘權重，以目標有標籤 train 及同樣 validation／早停設定訓練。OneStage／TwoStage 的差異是載入哪個 checkpoint，不是名字本身保證兩階段；代表 8000rpm 版本可能起點相同。必須確認 model file、scaler 與目標資料，不可混用。[微調][a-transfer]。

Lineage exp10 沒有神經權重更新：以少量目標健康支持集的中位數減來源健康 train 中位數得到 shift，評估時從目標 x 減 shift，再交來源 scaler／LW。它只修中心，不修完整共變異數或特徵語意。scratch 對照用同一支持集重新建目標健康基準；比較才知道重用舊量尺是否划算。[exp10][m-exp10]。

這不是 CORAL 完整二階分布對齊，也不是只看 A 完全不接觸 B：adapted 與 scratch 都看 B 的健康支持資料。50筆時 adapted健康接受9.31%、scratch87.90%，說明平移把排序修好卻沒修好尺度；數字來自同批72有方向配對，不能跨推為任何遷移學習都失敗。[原結果][r-exp10]。

**口頭說法：**「有標籤微調會改分類權重，健康平移只改輸入中心；我們要先說清 B 的哪些資料被允許看到。」**追問：這就叫跨馬達成功嗎？** 不行。使用目標支持集後的效果，不能冒稱 zero-shot；本次跨馬達通用診斷仍未解決。

### 6.24 Logistic regression：先把多類分類做成可查的基線

「線性」指每類 logit=`w_cᵀx+b_c`，不是只有兩類或沒有機率。softmax 將所有 logits 的指數除總和；cross-entropy 懲罰真類別機率太小，正則化限制權重過大。fit 學各類 w、b，預測選最大 logit；單靠 softmax 不會拒絕未知，需要另接 detector。

固定跨馬達基線使用 multinomial logistic、C=1、lbfgs、class_weight=balanced、max_iter=1000、seed 隨協定。balanced 降低樣本較多類的支配，不等於各馬達／轉速都已等權；所有表示 scaler 只 fit known train。N=5 全組合已知 accuracy 約25.74%，說明可執行基線不代表分類問題解決。[研究協定][research-openset]、[固定分類器 registry][research-registry]、[原始矩陣結論][research-final]。

**口頭說法：**「先用清楚的線性分類器檢查現有特徵與跨馬達邊界，再把未知拒絕獨立接上。」**追問：線性低分是否證明深網一定好？** 不證明；也可能是來源偏移或標籤重疊，須用相同切分作受控比較，不能跳過資料問題。

### 6.25 LDA：共享類內變動，找類別中心差

LDA 將每類視為不同中心、共用類內共變異數的 Gaussian 分布；選使類別判別分數最高者。直覺是「哪些方向的類別中心相差大，又不是類內本來就常亂晃」。shared covariance 使判別邊界線性，比各類各估一個完整矩陣省參數。

研究 C01 等採 sklearn solver=lsqr、shrinkage=auto、各已知類 equal priors；另固定 shrinkage .1／.5／.9 作對照，C24 按 RPM 各建模型。C17 使用 harmonic69 表示，不可將它與 C01 差值全當 LDA 變強。C17 seed0 三馬達等權已知39.29%、fault30.43%、健康總誤報14.13%、未知召回8.44%，依然不是可靠全流程。[registry][research-registry]、[實測][research-report]。

重要理論來源 Fisher（1936），*The use of multiple measurements in taxonomic problems*，[DOI](https://doi.org/10.1111/j.1469-1809.1936.tb02137.x)；目前多類 Gaussian／收縮實作與原二類案例不同。

**口頭說法：**「LDA 用共享類內量尺比較各類中心，收縮讓這個量尺較不容易估歪。」**追問：按 RPM 分模型一定更好？** 不是；它減少工況混合，也減少每個模型可用樣本，還沒解決馬達個體差異。

### 6.26 RDA-inspired：在逐類與共用共變異數間折衷

各類不同 covariance 可描述不同形狀，但樣本少時估計不穩；全共用較省參數又可能過度簡化。研究自訂 `B_c=(1−λ)Σ_c+λΣ_pool`，再 `Σ'_c=(1−γ)B_c+γtrace(B_c)/p I`。λ 控制共用程度，γ 控制向球收縮；fit 學每類中心、precision、log determinant，預測比較完整 Gaussian 二次分數，不能只選最小距離而漏掉體積項。

固定候選使用 pooling 0／0.5／1、shrinkage .1／.5 等已登錄配對、equal priors；不得 test 搜最有利組合。它直接混 covariance，與 Friedman 原作按樣本數混 scatter 的參數化不同，所以明稱 RDA-inspired。原作 Friedman（1989），*Regularized Discriminant Analysis*，JASA84:165–175，[DOI](https://doi.org/10.1080/01621459.1989.10478752)。本批有執行，未建立可外推的通用勝者。[模型][research-literature]、[候選與結果][research-report]。

**口頭說法：**「我們分開控制共用多少形狀與收縮多少相關，檢查偏差和小樣本穩定的取捨。」**追問：它就是 OAS 嗎？** 不是，RDA 這裡是分類器的 Gaussian 形狀折衷；OAS 是共變異數估計，可用於另一層拒絕。

### 6.27 Random Forest：多棵分類樹投票

分類樹以欄位條件反覆分資料，葉子保存類別分布。森林用重抽樣資料與隨機候選特徵建立多棵樹，再平均投票，減少單樹對訓練細節的依賴。它能表達非線性特徵交互，但樹在已見範圍外仍會走進某個葉子，不自動知道未知。

研究固定200樹、max_depth12、min_samples_leaf5、max_features=sqrt、balanced、n_jobs1，分別在 base75 或 harmonic69 known train fit，再接已知校準拒絕。未做 test 導向深度搜尋；沒有從原論文借用馬達改善數字。Breiman（2001），*Random Forests*，Machine Learning45:5–32，[作者原文](https://www.stat.berkeley.edu/~breiman/randomforest2001.pdf)。[實際參數][research-registry]。

**口頭說法：**「森林平均很多分類樹，降低單樹波動，但未知拒絕仍靠另外校準。」**追問：投票很一致就可信嗎？** 只表示這些樹對相同舊規則一致，工況偏移時可以一致地答錯；需新馬達測試。

### 6.28 ExtraTrees：再增加切分隨機性

ExtraTrees 也平均很多樹，節點對候選切值加入更多隨機，與 Random Forest 的主要差別是切分建立方式；sklearn 此設定預設不 bootstrap。增加隨機有時減少方差，也可能增加偏差，不能稱更隨機一定更穩健。

本研究使用與森林相同的200樹／depth12／leaf5／sqrt／balanced 限制；早期 known validation 曾選中 ExtraTrees，外層歷史曝光 test 的 known accuracy 約29.6306%→30.7605%，macro-F1 卻0.262007→0.252613，兩折變差。因此沒有只挑 accuracy 小升就換預設，也不能把早期選模與後來固定 C03 當同批成績。[原 follow-up][research-followup]、[registry][research-registry]。

Geurts、Ernst、Wehenkel（2006），*Extremely randomized trees*，Machine Learning63:3–42，[作者機構頁](https://orbi.uliege.be/handle/2268/9357)。**口頭說法：**「我們試過更隨機的樹，但一個平均指標增加並沒有同時改善各類與各馬達。」**追問：選模是否合法？** 要看 validation 是否真的獨立；早期跨折共同選模依賴後來另修正，歷史曝光仍不能消除。

### 6.29 Histogram Gradient Boosting：逐步修正分類損失

Boosting 不是獨立樹投票，而是一棵接一棵修正目前模型的損失梯度；histogram 先把連續值分箱，加速找分割。learning rate 控制每一步加多少，樹數與葉數控制容量；訓練損失下降仍不等於新馬達誤差下降。

研究固定learning_rate=.05、max_iter200、max_leaf_nodes15、min_samples_leaf20、L2=1、balanced、early_stopping=False。fit 只 known train，cal 定拒絕，不使用 test 選哪一輪。這是 sklearn histogram 實作，非完整重現 Friedman（2001）*Greedy function approximation: A gradient boosting machine*，[DOI](https://doi.org/10.1214/aos/1013203451)。[registry][research-registry]。

**口頭說法：**「它逐輪補分類器還沒學好的部分，是有標籤分類候選，不是 Isolation Forest 的異常樹。」**追問：為何關 early stopping？** 這批固定訓練步數以避免偷偷從非獨立資料選 checkpoint；固定步數也不保證最佳。

### 6.30 RBF-SVM：用核建立較彎曲的分類邊界

監督式 SVM 要讓不同標籤有分類間隔；RBF `K(x,z)=exp(−γ||x−z||²)` 讓近點相似度高、遠點低。C 控制違反間隔的代價，γ 控制相似度衰減範圍。與 OCSVM 不同，它看已知多類標籤來分界，自己仍沒有未知出口。

研究用 C=1、gamma=scale、balanced、probability=False，base75／harmonic69 等固定表示。來源為 Cortes、Vapnik（1995），*Support-vector networks*，Machine Learning20:273–297，[DOI](https://doi.org/10.1007/BF00994018)。同一類方法在早期 validation 與固定候選各有測試，沒有可靠跨馬達優勝；不能在 test 改 C／γ 後保留盲測名稱。[registry][research-registry]。

**口頭說法：**「我們讓分類邊界有非線性，但拒絕未知仍另外處理。」**追問：資料量小為何不保證 SVM 好？** 核可以貼合訓練群，若 B 馬達位置整片移開，舊邊界仍可能錯。

### 6.31 Gaussian Naive Bayes：簡化成各欄條件獨立

GNB 對每類、每欄估平均與變異，以 Gaussian 密度相乘再乘 prior 作分類。Naive 指給定類別後各欄獨立的假設，省掉全 covariance；計算以 log 相加避免很多小數相乘下溢。

研究固定equal priors、var_smoothing=1e−9；只 known train 建參數。105／75 維很多統計欄相關，違反獨立假設可能讓信心過大。它是低成本對照，不是經驗上已證最適模型。John、Langley（1995）*Estimating Continuous Distributions in Bayesian Classifiers* 的 Gaussian 對照是來源之一，[作者預印本](https://arxiv.org/abs/1302.4964)；此處沒有用該文的 kernel density 版本。[registry][research-registry]。

**口頭說法：**「GNB 用很多一維分布近似一個類，資料需求少，但忽略特徵間一起變的關係。」**追問：它和對角馬氏一樣嗎？** 有相似的獨立變異假設，但分類還比較 prior／分布體積；拒絕分數與校準角色不同。

### 6.32 k-NN 分類與開集 k-NN 的差別

分類版從已標記 train 找鄰居，用類別投票；研究 C07／C08 用 k=5／15、weights=distance、euclidean、brute、n_jobs1，距離較近的票較重。保存參考就是模型建立，預測不更新參考。[registry][research-registry]。

開集版卻是逐類算平均距離再除 cal 線，問「有沒有任何已知類足夠近」。分類可以選類 A，但拒絕器仍覺得離所有已知太遠；將二者解耦才能量化錯類與漏拒絕。E 批次對角學習後的 k-NN 比 identity 分類反而降約3.507／3.655百分點，說明學距離不一定有利實際鄰居。[完整配對][research-report]。

**口頭說法：**「投票決定哪一類，距離門檻決定要不要接受；不能把有一個最近鄰當作已知證明。」**追問：k 改15就是新演算法？** 只是同方法的固定參數對照，不增加獨立研究資料。

### 6.33 特徵視圖：保留、去重、幅值與形狀

表示比較先問「改的是模型，還是模型看到的數字」。base75 取振動；base66 去掉可驗證的冗餘關係，如 RMS²／MSA、std²／variance 及歷史重複指標。程式先 verify_redundancy，不能對不符合關係的新資料硬刪；signed66 用 train 尺度作 signed-log，壓縮大幅值但保留正負。

harmonic66 把每軸十個 band maxima 除總絕對幅值，強調相對形狀；harmonic69 再保留三個 log 幅值座標，避免把故障振幅資訊全部消去。floor 由 train 決定以防近零除法。GainRepresentation 的63／66／69維還將部分統計量除 RMS，再逐步加回相對與絕對幅值；這些是有限代數改編，不是修復 raw 同步，也不是新增頻譜採集。[表示程式][research-literature]、[gain 程式][research-continuous]。

若感測增益確實是 nuisance，比例可能減少偏移；若振幅正是故障訊號，比例也會抹掉答案。未知物理原因只能當假說。105→75 在固定研究有局部改善，Q／後續批次仍未通過保護條件，不能宣稱任何無因次化都有效。

**口頭說法：**「我們把幅值與形狀分開試，保留只改一部分的控制，檢查移除幅值是去掉干擾還是去掉故障。」**追問：這算原創物理特徵嗎？** 不是由新物理採樣推導的發現，主要是既有正式特徵的版本化轉換與實驗。

### 6.34 NCA：學讓同類鄰居較容易被選中的投影

NCA 學一個線性矩陣 A，使轉換後距離 `||Ax_i−Ax_j||` 對同標籤鄰居較有利；用平滑的鄰居機率最佳化，而非只保留最大 variance。fit 讀 known train labels，cal／test 只乘固定 A。它與 PCA 不同，也不是完整 LMNN。

研究 NCA10 先train-only RobustScaler，每類最多60 train窗、PCA起始、max_iter50、tol1e−5、seed0／1／2，投影10維再k5分類；保存subset IDs、n_iter 與預算是否到頂。使用子集是計算折衷，達50輪不能改寫成全資料全域最佳。該家族沒有解決跨馬達最差組。[模型][research-literature]。

Goldberger、Roweis、Hinton、Salakhutdinov（2004），*Neighbourhood Components Analysis*，NIPS17，[原文](https://papers.nips.cc/paper/2566-neighbourhood-components-analysis.pdf)。**口頭說法：**「NCA 是有標籤投影，讓鄰居分類較有利；我們受預算限制只做固定小子集。」**追問：train 鄰居好就會跨 motor 好？** 不保證，學到的也可能是 A 馬達特有的類別關係。

### 6.35 LMNN-inspired 對角距離：拉近同類、推開冒入者

先固定每個 train 點三個同類 target neighbors；損失一部分拉近 target，一部分對異類比 target 還近的 impostor 加 hinge 懲罰 `max(0,1+d_target−d_other)`。本實作只學各維非負權重 w，距離 `Σw_j(x_j−z_j)²`，等於先乘 sqrt(w) 再歐氏；不能表達任意旋轉的完整 PSD 馬氏矩陣。

固定train class×RPM 每格最多20、總≤360，pull／push 各0.5、identity ridge0.01、L-BFGS-B；hard150／smooth150／hard600 是損失與最佳化預算的有限對照，未知不參與學權重。非負保證平方距離不負，但不保證 domain invariant。收斂失敗必須保留 INCOMPLETE，不能套 identity 假裝學成功。[程式][research-continuous]、[solver 來源][research-solver]。

Weinberger、Saul（2009），*Distance Metric Learning for Large Margin Nearest Neighbor Classification*，JMLR10:207–244，[原刊](https://jmlr.org/papers/v10/weinberger09a.html)。本案改成對角、平均項與ridge，不是完整論文重現。hard600 全九 fits 收斂，但 E 的分類仍比 identity 下降，反駁的是這個有限設定的充分性。

**口頭說法：**「我們讓某些特徵對鄰居距離更重要，僅在 train 學；先分清求解器是否成功，再看跨馬達是否真的改善。」**追問：loss 下降是不是成果？** 是訓練目標下降的證據，不是 final 分類或健康誤報合格。

### 6.36 Margin-energy 分類：假設一個類別後算關係代價

這裡 energy 不是 OOD 的 logsumexp。模型對新點逐一假設類 c，算同類 target 距離的 pull，還算新點與異類形成的 outgoing hinge、以及新點若侵入舊 target 鄰域的 incoming hinge；三項保留求和，再選代價最小類。它保存最多360筆train參考、固定k3／mu0.5及已學對角權重，query不改reference。[分類實作][research-metric]。

這是 Weinberger、Saul 文中分類準則的有限接法，與一般k5投票、單中心分類分開試。取target時用原表示空間，真正平方距離用封存權重，來源必須一致。E 有完整外層測試但全方法未過契約，不能把名稱 energy 與另一套 OOD 分數混用。

**口頭說法：**「它比較把新點當成每個類別後，會破壞多少既有鄰域關係。」**追問：是否拿 test 真類別算？** 不是；各類都是假設評分，只有 train label 形成參考，test truth 只在事後核對。

### 6.37 LFDA：保留同類的局部多群

一般 LDA 偏向把同類整團壓近；同類在不同 RPM 可能有多個子群，LFDA 用局部相似度加權類內與類間 scatter，希望保留多峰結構。先在同類內取第7鄰居定局部尺度，以 Gaussian affinity 計權，再解 `S_b v=λ(S_w+ridge I)v`；保留大正特徵值方向，類內變動受抑制、類間對比受強調。

本案同一合法train子集≤360、投影10／20維、ridge按trace定小量，檢查正方向與eigen residual，並有匹配PCA對照；cal／test不fit投影。不是原文所有超參數與資料集的複製。F 的16方法全部未過跨馬達契約，即使投影數值正確，也沒有可靠泛化。[實作][research-lfda]、[結果][research-report]。

Sugiyama（2007），*Dimensionality Reduction of Multimodal Labeled Data by Local Fisher Discriminant Analysis*，JMLR8:1027–1061，[原刊](https://www.jmlr.org/papers/v8/sugiyama07b.html)。**口頭說法：**「LFDA 不強迫同類只有一球，而是利用局部鄰域學投影。」**追問：局部尺度一定可信嗎？** 小子集與跨個體偏移仍可能讓鄰居不代表未來，因此只作有限比較。

### 6.38 單／多原型與 KMeans：用代表點省下全部參考

單原型是每類train均值，多原型用該類KMeans得到三中心；預測選距離最近原型的標籤。KMeans 重複指派最近中心與更新均值，減少類內平方距離，不知道 unknown。它與HDBSCAN不同：中心數事先指定，沒有同樣的噪聲處理。

本研究1／3中心、KMeans n_init10、max_iter300、tol1e−4、lloyd，初始化只讀known train。多中心能表達多峰，也可能把個體／工況特有群記住。另個 novelty 候選用每類2中心加pooled-LW precision，不能和三中心分類器視為同設定。[原型程式][research-metric]、[novelty][research-literature]。

**口頭說法：**「先用少數代表點做清楚基線，再問學著移動原型是否真的有幫助。」**追問：三中心就是三種故障嗎？** 不是，是同一已知標籤內的三個幾何代表，不新增物理類別。

### 6.39 GLVQ 改編：移動原型改善相對距離

對每個train點，d+ 是最近同類原型距離，d− 是最近異類距離；`μ=(d+−d−)/(d++d−+ε)`。μ負表示同類較近；損失平均 `sigmoid(4μ)`，希望μ更負。fit 更新原型位置，不更換資料標籤；推論選最近原型。

本案由全部known train的1／3中心初始化，在固定≤360子集算損失；static不移動、GLVQ移動、anchored再加0.01回初始原型的懲罰。ε=1e−12，L-BFGS-B最多600iter／2000fun、單模型120秒；未收斂保存狀態但禁止推論。G 的24候選全部未過契約，不靠改名說成新成功演算法。[程式][research-glvq]。

Sato、Yamada（1995會議／1996卷出版），*Generalized Learning Vector Quantization*，NIPS8:423–429，[原文](https://proceedings.neurips.cc/paper_files/paper/1995/file/9c3b1830513cc3b8fc4b76635d32e692-Paper.pdf)。本案固定β、平均損失與anchor為改編。**口頭說法：**「我們直接調代表點，使同類比異類更近，再看這種訓練改善能否延伸到新馬達。」**追問：靜態均值對照為何重要？** 才能分出效果是多中心／表示帶來，還是最佳化移動帶來。

### 6.40 平滑 L1 原型距離：減少大偏差被平方放大

平方距離對大差異欄很敏感，L1 用絕對差總和，但絕對值在零點不光滑。研究試兩種平滑：`Qα(z)=|z|+2log(1+exp(−α|z|))/α`，`Sα(z)=z tanh(αz/2)`，z為單欄x−prototype，α=20；對所有欄相加再進GLVQ相對損失。α大時更近絕對值，不是損傷嚴重度參數。

Q在z=0仍有2log2/α，故不是零對角metric；程式保留原式常數，沒有偷偷減掉。只用每類一均值初始化，static／GLVQ／anchor，identity或既有對角幾何，固定C02拒絕器。H 的12候選全部未過契約，表示這些固定改編沒有解決問題，不否定所有L1方法。[程式][research-l1]。

Lange、Zühlke、Holz、Villmann（2014），*Applications of lp-Norms and their Smooth Approximations for Gradient Based Learning Vector Quantization*，ESANN:271–276，[原文](https://www.esann.org/sites/default/files/proceedings/legacy/es2014-153.pdf)。**口頭說法：**「只改距離對偏差的反應，和同條件平方距離配對，檢查是否減少單欄支配。」**追問：L1比較穩健就一定較好？** 若大幅度正是故障資訊，抑制它也可能降低分類能力。

### 6.41 RPM-aware 原型：原型隨可觀察工況改變

若同配置均值隨RPM改變，固定一個中心會混工況。研究把 `c=(RPM−8000)/3000`，每類原型寫成 `w(c)=θ0+θ1c` 或再加θ2c²；先用全部known train每類最小平方初始化係數，再在固定子集做GLVQ類損失，auxiliary可加0.01的真類原型重建MSE。

只有6000／8000／11000三離散RPM，二次static可剛好對上各RPM均值；這是容量控制，不是已證未見RPM外插。推論允許看RPM，不看motor路徑或test真標籤。AGLVQ原文用不同距離、activation與pretrain；本站只是context機制有限改編。I 的12候選全部未過契約，固定C02拒絕也不能自行改善T1 unknown floor。[程式][research-context]。

Graeber、Vetter、Saralajew、Unterreiner、Schramm（2021），*AGLVQ – Making Generalized Learning Vector Quantization Aware of Context*，ESANN:557–562，[DOI](https://doi.org/10.14428/esann/2021.ES2021-40)。**口頭說法：**「讓原型依已知RPM條件化，區分工況變化與類別變化，但個體差異仍可能超過這個補償。」**追問：RPM是否偷看答案？** RPM是允許的工況輸入，不是故障label；仍須確認未來可取得且量測語意一致。

### 6.42 三軸排列不變核：不怕交換軸名，仍不等於旋轉不變

66維視圖可排成三軸×22欄。研究對Y的六種軸排列各算RBF相似度，取平均，再以α=0／0.5／1與原核混合；gamma=1/66。若所有軸同名量共享train scaler，排列平均可減少單純換軸順序的影響。

fit以precomputed kernel訓練balanced SVC（C1），保存train reference及support；拒絕則用核空間的類中心平方距離，known cal q95。分塊128列是記憶體安排，不改科學模型。K 九候選全部未過契約；真實任意角度旋轉不只交換三軸，已算統計與band maxima也未必能直接旋轉回去。[程式][research-axis]。

方法機制依Haasdonk、Burkhardt的群不變核文獻，本站有限六排列及凸混合另列[原始來源卡][research-citations]，不假稱重新安裝感測器做了旋轉實驗。**口頭說法：**「我們只檢查軸排列這個有限干擾，不宣稱消除了所有安裝差。」**追問：核距離從哪來？** 由K(x,x)−2平均K(x,類train)+類內平均K求類中心距離，不是把二維圖距離拿來當拒絕。

### 6.43 REx：讓三個訓練 RPM 的風險不要差太多

風險在此是每個RPM的加權cross-entropy。REx類目標為 `mean(R_r)+β Var(R_r)+ridge`；β=0是等RPM ERM，β1／10加重風險差異懲罰。先同來源fit ERM，再以其權重warm-start其他β，只讀known train，不能用測試馬達當訓練環境。

研究每RPM／class等權、ridge=.001、L-BFGS-B最多1000iter，缺任一訓練RPM中的已知類就INCOMPLETE。收斂不代表有因果不變性；RPM三環境也未涵蓋未知motor。L 18候選全未過契約，即使54 fits收斂亦保留負面結果。[實作][research-rex]。

Krueger等（2021），*Out-of-Distribution Generalization via Risk Extrapolation (REx)*，ICML／PMLR139:5815–5826，[原刊](https://proceedings.mlr.press/v139/krueger21a.html)。**口頭說法：**「我們懲罰模型只在某個訓練轉速特別好，但相同轉速跨馬達仍可能有新偏移。」**追問：風險相同是否代表都好？** 不是，也可能三個都一樣差，所以同時看平均損失與外層各類成績。

### 6.44 RSC-inspired 自挑戰：遮住最依賴的特徵再學

直覺是模型若只靠容易的欄位，故意遮掉它，迫使使用其他線索。研究版是**表格線性分類器**，由同來源ERM起跑，依random／真類signed gradient／輸入×權重contribution建立候選mask；每窗遮ceil(D/3)欄，再挑真類機率下降最多的ceil(n/3)個train窗真正遮蔽，與unmasked對照。

固定full-batch SGD200步，step size由train weighted trace定，mask停止梯度，使用最後iterate；沒有宣稱收斂或由test選最佳輪。推論不遮樣本，只用學完權重。M 24候選、216格全部未過契約，某些平均分類小增仍有整類零召回與工況健康100%誤報。[實作][research-rsc]。

Huang、Wang、Xing、Huang（2020），*Self-Challenging Improves Cross-Domain Generalization*，ECCV，[作者預印本](https://arxiv.org/abs/2007.02454)。本站沒有複製原CNN訓練或Adam設定。**口頭說法：**「我們試著不讓線性模型只靠最顯眼欄位，但有限遮蔽訓練沒有解決跨個體。」**追問：訓練完成可稱成功嗎？** 只稱固定步數完成，科學效果依保護契約另判FAILED。

### 6.45 研究拒絕分數：改參考形狀不等於改分類器

#### 6.45.1 Pooled-within Mahalanobis

輸入為train的known特徵與類別。先各類減自己的中心，把殘差合併估一個共享LW covariance，再用各類中心與同一precision計分，取最小類距離。這在「各類雜訊形狀近似」時可用更多資料穩定估計；但不同配置若有不同變動方向，共享形狀會偏。known cal另定q95，不用test決定是否共享。它改的是拒絕參考，未必改分類labels。

**口頭說法：**「逐類中心保留，但所有類共用變動形狀。」**追問：和把所有train不分類直接估cov一樣嗎？** 不一樣，先扣各類中心，才不把類間中心差也當正常類內變動。研究C有實測，但沒有可靠跨馬達替換結論。

#### 6.45.2 Diagonal Mahalanobis

train按類估中心和各欄variance，precision只留對角項，相當於加總各欄標準化平方偏差。少估許多相關參數，適合樣本不足的控制；代價是無法分辨沿相關方向與違反相關方向的偏離。cal仍獨立，不能靠test加variance讓誤報好看。

**口頭說法：**「先拿掉欄位相關，檢查複雜covariance是否反而不穩。」**追問：就是原資料Euclidean嗎？** 不是，欄位仍按train變異加權；只有各variance相同時才差一個尺度。研究對照沒有證明忽略相關能解決motor shift。

#### 6.45.3 Relative Mahalanobis（RMD）

以最小類平方距離減背景全train平方距離的固定倍數：`s=min_c d_c²−λd_background²`，λ=.5／1／2。類模型與背景模型都只fit train。希望扣掉所有已知共有的背景方向，強調相對類別陌生程度；分數可負，所以直接比known-cal原始q95，不能除負門檻後仍說>1拒絕。Ren等（2021），*A Simple Fix to Mahalanobis Distance for Improving Near-OOD Detection*，[原文](https://arxiv.org/abs/2106.09022)。

**口頭說法：**「除了問離哪類遠，也扣掉對整個已知背景都遠的部分。」**追問：背景相減會不會把真正未知抵銷？** 會，取決於未知相對類與背景的幾何；因此三個λ是固定對照，不從test挑最佳，也沒有來源論文的部署保證。

#### 6.45.4 每類多中心

train每類用KMeans找兩個中心，距離使用共享precision，對所有中心取最小值。這容許同類有多個局部模式，不強迫一個橢球中心解釋全部RPM；中心數也是固定假設，不是資料證明有兩種機制。known cal在同一分數上定線。更多中心可能同時覆蓋未知，所以類內貼合與未知可分須分開量。

**口頭說法：**「用兩個代表區取代一個中心，測試多峰是否是問題。」**追問：群分成兩個就是兩種故障嗎？** 不是，可能只是工況或量測變動；本研究沒有替中心賦物理病因。

#### 6.45.5 Gaussian Mixture Model（GMM）

每類2個diagonal Gaussian，以EM交替估成分責任與參數，reg_covar=1e−4、n_init1、max_iter200，未收斂列不完整、不用末參數冒充成功。輸入known train；分數取最相容類的負log-density，known cal定q95。與多中心距離不同，它另估混合比例和各成分variance。密度小可因新motor而低，也可因真未知而低，不能只從分數判原因。EM重要來源Dempster、Laird、Rubin（1977），JRSSB39:1–38，[DOI](https://doi.org/10.1111/j.2517-6161.1977.tb01600.x)。[全部實作][research-literature]。

**口頭說法：**「用兩個機率分布解釋同一類，而不只量到最近中心。」**追問：機率密度就是故障機率嗎？** 不是，連續密度有單位且依表示變換改變；它不是P(故障｜訊號)，也不保證未知密度低。

這些方法都有研究執行／不完整條件紀錄，不全是主線可切換選項；C的固定參考與後續契約未產生可信部署winner。**口頭說法：**「我們分別改共享形狀、背景扣除或每類多峰，檢查是哪種幾何假設不合適。」**追問：為何不用一律正規化到1？** 有正負分數時除法會改方向；判定須依該分數定義，不能只看共同欄名。

### 6.46 信心型拒絕：MSP、entropy、margin、energy 與 ViM

#### 6.46.1 Maximum Softmax Probability（MSP）

先以known train擬合多類分類器，推論取得K類posterior，異常分數`1−max_c p_c`；known cal的raw q95定線。它假設陌生輸入讓分類器較不確定，但線性外推可能給陌生點更高信心。Hendrycks、Gimpel（2017）的基線是來源，[原文](https://arxiv.org/abs/1610.02136)。本站是表格分類器適配，不是該深網實驗。

**口頭說法：**「看最有把握的一類還剩多少把握。」**追問：只有健康一類可用嗎？** 單類posterior永遠為1，不能據此辨未知；P1缺條件時列N/A。

#### 6.46.2 Normalized entropy

同樣讀train分類器的posterior，算`−Σp_c log p_c/log K`，K>1，零項按極限0處理；known cal另定線。愈平均愈高，使用全部類別而非只看最高一類；確信錯分仍會漏掉，且K與機率品質會改尺度。沒有另訓練entropy模型，未把test用作溫度校準。

**口頭說法：**「看整張類別分布有多分散。」**追問：和MSP排序一定一樣嗎？** 不一定，相同最高機率下其餘質量可集中或分散；因此需要獨立對照，不能重複計成新資料。

#### 6.46.3 Top-two probability margin

先排序posterior，算`1−(p第一−p第二)`，known cal定線。它只問前兩名是否難分；第三名以後完全忽略，與entropy的假設不同。高分可表示兩種已知配置本來相近，未必是未知；全部已知類都遠但某一類外推特別高時反而漏報。

**口頭說法：**「第一名有沒有明顯贏第二名？」**追問：margin低可排除故障嗎？** 不能，它描述分類競爭，不是物理安全。這兩項是研究固定對照，沒有各自通過跨馬達可靠性。

#### 6.46.4 Energy

取`−T log Σexp(logit_c/T)`，本版T=1、使用train所fit的LDA affine logits，愈高較陌生；known cal定raw q95。所有logits一起加常數時softmax不變但energy改變，故logit gauge與分類器尺度重要；不能把tree的log(probability)冒稱原深網logits。Liu等（2020），*Energy-based Out-of-distribution Detection*，[原刊](https://papers.neurips.cc/paper/2020/hash/f5496252609c43eb8a3d147ab9b9c006-Abstract.html)。

**口頭說法：**「保留類別logits的共同強度，不只看歸一化後誰勝出。」**追問：有energy分數就算重現該論文嗎？** 不是，本版沒有其深網energy訓練或外部OOD資料；只做可計算的表格分數對照。

#### 6.46.5 Virtual-logit Matching（ViM）

先由train分類器W、b求原點o=−pinv(W)b，再用train相對o的二階矩找principal rank20；殘差長度乘train估計α，再減logsumexp(logits)，known cal定線。它結合特徵離主空間與分類反應，α非正就記失敗、不取絕對值美化。Wang等（2022），*ViM: Out-Of-Distribution with Virtual-logit Matching*，[原刊](https://openaccess.thecvf.com/content/CVPR2022/html/Wang_ViM_Out-of-Distribution_With_Virtual-Logit_Matching_CVPR_2022_paper.html)。

**口頭說法：**「把主特徵空間外的殘差和分類反應放在一起看。」**追問：為何不能用test挑rank？** 會用答案調拒絕幾何；本版固定20，且手工特徵／LDA並非原論文深表示，因此只支持本適配的結果。

這些是LDA／表格特徵改編，未做energy深網訓練或原ViM影像重現；P1 healthy-only 中相應方法因缺條件列N/A，後來C有可用多類分類器才實作部分分數，不能一律說「有提過就測過」。全部用known cal定各自線，未產生可靠跨馬達替換。[實作與條件][research-literature]、[方法來源與未測清單][research-sources]。

**口頭說法：**「分類器的猶豫可以當拒絕線索，但未知也可能被高信心錯分，所以要和距離分開驗證。」**追問：confidence高就安全嗎？** 不是，分布偏移下高信心錯誤仍存在，且本版不是校準過的設備安全機率。

### 6.47 預測類路由與分數融合

主線取min-over-classes，研究R17改用分類器預測的那一類距離；cal也按**預測類**分組q95，不用cal真類別替推論挑路。若某類沒有被預測到而缺校準組，記INCOMPLETE、不借其他fold或真值補。這能檢查分類與拒絕是否一致，也會讓分類錯誤傳到拒絕。[實作][research-literature]。

R21／R22則把factory距離與1−MSP在known cal上用median／IQR標準化，固定距離權重.25或.75融合，再以global known-cal q95定線；不看test選權重。分類器與detector分開接的D/P研究也不等於融合數字，前者可只換一個元件檢查因果。

D01比C02的分類有局部改善，但未知召回完全相同，因為detector沒換。這是受控比較的合理結果，不是程式忘記更新。**口頭說法：**「我們讓錯分與拒絕各自可查，避免一個改善欄掩蓋另一層沒動。」**追問：固定融合一定公平嗎？** 參數固定只是條件之一，還要相同資料角色、來源與測試曝光界線。

### 6.48 t-SNE：畫出局部相似，不建立診斷規則

t-SNE 先把高維近遠轉成局部鄰居機率，再在二維調整點位置，使兩種鄰居關係較一致。perplexity控制局部鄰域尺度，seed影響初始與最佳化；群間遠近與大小會受投影影響，不能拿二維空白距離當物理差異。

exp12 每類最多抽200窗、seed42、perplexity30，對合併樣本共同求圖；sample可能含train，圖不是獨立test classifier。沒有利用t-SNE座標作目前拒絕，也沒把它當新特徵fit可部署模型。van der Maaten、Hinton（2008），*Visualizing Data using t-SNE*，JMLR9:2579–2605，[原刊](https://www.jmlr.org/papers/v9/vandermaaten08a.html)。[實驗程式][m-exp12]。

**口頭說法：**「t-SNE幫我們探索局部結構，效果還是以原空間的holdout指標說明。」**追問：圖分很開是否可證明泛化？** 不能，可能是抽樣、工況或投影造成；未見馬達仍須獨立評估。

### 6.49 Replay 更新：限制記得多少，而不是換一個名稱

新類確認後重新fit，需要決定可讀哪些舊資料。full historical replay保留歷史到達樣本；random fixed memory用固定容量隨機保留；balanced memory盡量各已學類均衡；new-class-only只留當下類；full-pool oracle額外取得完整池。它們是資料可用性與記憶體策略，不是本輪完整實作EWC或iCaRL。

研究容量與每類到達budget10／25／50／100固定，已知健康train／cal保留，故障到達樣本再分fit／cal，固定test不加入。樣本太少時估計不穩、舊類可能遺忘；oracle有更多未來樣本，不能和arrival-only混成同樣條件。240列研究有低或零新類召回，沒有可靠持續診斷winner。[更新研究程式][research-continual-code]。

**口頭說法：**「持續學習先問允許記住哪些已確認資料，再量新類學會多少、舊類忘多少；全池更新只是有利參考。」**追問：主Web就是這種受限replay嗎？** 不是，主線確認後讀完整配置池，兩套結果要分開。

### 6.50 尚未實作的方法：知道原理不等於宣稱測過

Deep SVDD要訓練網路讓健康表示靠近中心；OpenMax要有可追溯activation與尾部分布擬合，重分配未知分數；CORAL要明確定義來源／目標二階對齊與允許的target access。P1無相應深表示／logits／Weibull鏈，故列N/A；exp10中心平移不是完整CORAL。沒有可追溯raw時，也不能把105欄硬排成時間訊號做STFT／wavelet／raw CNN。

Group DRO 的構想是增加最差known group損失的權重，讓模型不要只顧平均；但N批只有手冊與規劃216格，實作、fit、test均為0。沒有損失下降或研究分數可報，不能寫「試了但無效」。原始方法與適用缺口由[研究來源清冊][research-sources]及[Group DRO先行手冊][research-dro-plan]保存。

**口頭說法：**「我們有查過這些方向，但缺方法所需資料或尚未實作，所以不把它們算進已測演算法。」**追問：為何不繼續全部試？** 來源與跨馬達驗證的瓶頸未解，且本階段已因時間停止無界模型搜尋，不能用更多名稱取代有效證據。

## 7. 從健康基準走到新類更新

### 7.1 把各方法接成一條流程

```text
已知健康 train ─→ scaler／detector擬合 ─┐
已知健康 cal ───→ 拒絕門檻 ───────────┤
                                      ▼
一窗輸入 → 計分 → score≤1？ → 接受為健康或已知配置
                    │否
                    ▼
              顯示未知／更新趨勢
                    │score>2 且分類為未知
                    ▼
                隔離區累積
                    │每10個新隔離窗、數量足夠
                    ▼
               HDBSCAN分群
            無群：繼續等 │ 合格候選≥25
                        ▼
                 操作員確認（模擬）
                  │             │
               已知邊界群      新配置
               清該群、不學    讀完整標記池
                                ▼
                        切分／重擬合全部已知
                                ▼
                       更新幾何／快照，繼續監測
```

這是CSV研究流程；沒有新增感測設備接口，也沒有自動修復馬達。score、分類、方向與趨勢可以同時存在，只有對應門檻與規則才改狀態，不因圖上某點看起來很遠就直接確認新類。[session][m-exp2]、[監測器][m-monitor]。

### 7.2 每步誰決定，產生什麼

| 步驟 | 輸入與動作 | 決定者／輸出 | 失敗或不足時 |
|---|---|---|---|
| 資料選擇 | 讀所選工況合法105欄CSV | loader回pool與audit | 不合法整次拒絕，不能補亂數。 |
| 健康基準 | 健康split，train fit scaler與detector，cal定線 | 程式建立固定參考 | fit未完成不得score／classify／project。 |
| 逐窗判斷 | 同一scaler transform，再算每類正規化分數 | 最小分數>1為未知 | 超線不是病因，需工況／品質檢查。 |
| 隔離 | 未知且score>2才保存窗與到達序號 | 程式累積候選材料 | 1到2之間仍未知，但不進新類發現。 |
| 分群 | 對隔離窗縮放後HDBSCAN | 最大合格密度群 | 無群繼續收集，失敗計數增加。 |
| 候選標記 | 幾何群索引對照真值快取 | 多數配置、purity、是否已知 | 真值已被後端讀，不稱全盲命名。 |
| 確認 | 操作員按確認或批次自動模擬 | 已知群退回／新配置納入 | 無候選、過期候選應拒絕。 |
| 更新 | 新配置完整池切split，全部已知重fit | 新detector、PCA、rays與快照 | 沒有完整交易回滾保證，錯誤須停查。 |

「未知」線設1，「隔離」線設2，是把敏感提醒與新類發現分開。這批資料健康誤報常剛超1，故障常遠高於2，較高隔離線可降低假候選；但在另一批資料若真正故障只有1.5，便可能提醒卻無法發現群。所以這是有代價的設定，不是普遍不漏的保證。

### 7.3 候選不是答案，確認不是重新量測

密度階梯只改找群方式，不改score判斷線。候選記錄size、purity、蒐集t範圍與參數；某一stage新注入配置不一定是最後學到配置，因隔離區可能還有上一段殘留，結果應讀learned欄，不只讀注入名稱。

目前 truth 被傳入process保存；_try_cluster 已計多數、purity、is_known，confirm 用這些資訊模擬人員。分群距離不使用label，與「整個系統從未接觸label」不同。新導覽可匿名顯示來源、確認後揭示，但不會改後端真值可用性。

已知群退回只清該群；新配置加入後清隔離區中所有同truth配置，重fit讀完整池。原先已知split保留，新類才新增split，scaler卻重fit全部known train，PCA圖會換座標；其他已知的決策也可能改。要評估更新，不只測新類，也要重看健康與舊類表現。[confirm][m-exp2]。

### 7.4 一個示意案例

假設以T1／8000rpm健康建立基準。第一窗score0.8，接受；下一窗1.2，顯示未知並影響趨勢，但不隔離；另一來源連續多窗score約3，才逐筆進隔離區。25個窗只是最低候選規則，HDBSCAN可能仍把它們判噪聲，需更多資料。

稍後出現合格群，操作者確認為7screws。系統不是把這個群直接當全部訓練資料，而是讀7screws完整標記池，再分train／cal／holdout重fit；之後相同來源可能score0.7並被認成已知故障。以上0.8／1.2／3／0.7都是示意；模型認識了故障，不代表螺絲回到8顆，也不代表健康指標已物理校準。

### 7.5 如何量化這條流程

發現率是哪些注入配置在預定上限內形成可確認候選；samples_to_candidate是到達tick數，不一定unique samples。purity是候選多數truth比例，不能代替整池召回；own_holdout_acc是新類切分後自類接受／分類結果，healthy_holdout_acc檢查健康是否被破壞。還應看舊類召回、重複到達與未來樣本是否被讀。

主線exp2完整池oracle能示範「有足夠已確認資料時流程怎麼接」，不是arrival-only的公平驗收。研究replay另限制到達IDs與固定test，兩種角色分開才知道更新成本與遺忘。函數存在、跑出候選、每類都被加入與新設備可泛化，是不同證據程度。

### 7.6 不順利時如何說明

沒有候選：可能資料不足、密度不成群、隔離線排除了邊界窗，不能先宣稱演算法壞掉；看隔離、嘗試與source。錯誤更新：known已註冊但fit可能失敗，_fitted=False會擋後續推論；它保護不使用半完成模型，卻沒有回到先前完整狀態的交易保證。

Web的pause只停tick，不是設備停機；reset回健康模型、session epoch變化，不能和舊模型的score軸直接接成一條物理歷程。重連先同步完整state與active source，避免把下拉選項誤當後端已切換。具體現在有的保存與控制保護，系統章會依最新修正說明。

**完整短講：**「我們把未知提醒和新類發現分開：1以上先拒絕，2以上才收集。HDBSCAN只提出群，人員確認才有標記；目前確認用完整配置池重建，所以是oracle示範。更新後同樣故障被認得，並不代表恢復健康；我們還要看舊類與健康是否退步。」

**追問：為什麼不全自動命名？** 幾何相近只證訊號相似，沒有病因真值；自動多數標記來自研究標籤，不是分群自發現故障原因。**追問：25筆是否足夠學新類？** 只是一個候選規則，本版實際fit讀更多完整池資料，不能據此聲稱25筆訓練就夠。
