# 偵測方法知識庫（AI 問答用）

本檔由 `src/web/assistant.py` 的 `lookup_knowledge` 工具依「## 」標題切段檢索。
數字取自程式預設值；程式改了參數，這裡要跟著改。

## 資料與特徵

- 每一筆樣本 = 1 秒振動訊號抽出的 105 維特徵（固定維度），來源是
  `data/Step-*/myfeature/**/*_Group_feature_data_clean.csv`，本專案唯讀。
- 資料集 = 馬達代碼（T1／T2／T3）× 轉速目錄（例如 8000rpm），共 9 組，以掃描目錄為準（`core.data.discover_datasets`）。
- 已知類別切分 train/cal/holdout = 60/20/20（`core.data.make_split`），seed 預設 42。

## 螺絲配置（故障類別）

健康基準是 8screws（8 顆螺絲全鎖）。其餘配置代表馬達座鬆動程度：

| 配置 | 意義 |
|---|---|
| 8screws | Healthy（8 螺絲全鎖） |
| 7screws | 最輕微鬆動 |
| 6screws | 輕微鬆動 |
| 5screws | 中度鬆動 |
| 4screws | 明顯鬆動 |
| 3screws | 嚴重鬆動 |
| 2screws | 很嚴重鬆動 |
| 1screw／1screws | 最嚴重鬆動（兩種目錄名都出現過） |
| 3_14screws | 複合不均勻鬆動 |
| 4_146screws | 複合不均勻鬆動 |

## 冷啟動流程

1. 一開始只認識健康（階段 0）。
2. 每筆樣本算開集分數；超過 1.0 判為「未知」。
3. 分數超過隔離線 2.0 的未知樣本進「隔離區」；1.0～2.0 之間只警報、不參與新類發現。
4. 隔離區每累積 10 筆新樣本試一次 HDBSCAN 分群。
5. 聚出 ≥ 25 筆的穩定叢集 → 產生「候選新故障」。
6. 新類怎麼納入，看是哪個頁面：
   - 實驗頁的實驗二（▶ 執行與 ⏵ 邊跑邊畫）不等操作員確認。候選一成群就只用這一群樣本自學，
     類名是「模型新類 N」（discovered-N），不讀真實配置，也不用完整配置池。群不到 5 筆就不納入。
     真實配置的多數與純度只放在「事後對照」，不是系統判定。
   - 首頁即時展示與獨立導覽保留「操作員確認」按鈕：按下才揭示真實身分，讀該配置的完整資料重新擬合。
     若叢集其實是已知類別的邊界樣本，回傳 rejected_known：退回、清出隔離區，量尺不變。

未知資料絕不參與擬合：訓練、校準、閾值只用已知類別。

## 開集分數與判定

- 預設方法 Mahalanobis，逐類 Ledoit–Wolf 共變異數；可改逐類 k-NN 距離（k = 5）。
- 每類以校準集距離的第 95 百分位（confidence 0.95）當閾值，分數 = 距離 ÷ 閾值。
- 判定：分數 ≤ 1 屬於某已知類別（健康或已學會的故障）；所有類別分數都 > 1 → 未知。
- 「相對偏離量尺」= min(1, 1/score) × 100%，只供展示，不是損壞百分比、不是剩餘壽命。

## 健康誤報率

健康樣本的誤報率約 10.9%（名目 5%），原因是校準集只有約 62 筆的有限樣本效應，屬已知結果。
誤報分數通常只些微超線（實測 1.01–1.08），真實故障最低分 ≥ 10。
所以單筆偶發「未知」不代表故障；要看 EWMA 是否持續上升、隔離區是否累積。

## 變化點分析（EWMA）

- 對「是否判為未知」做 EWMA，alpha = 0.08，warmup 10 筆，視窗 120 筆（`core.trend.TrendMonitor`）。
- EWMA ≥ 0.5 觸發警報；[0.2, 0.5) 是中間帶。
- 警報當下回頭數中間帶停留筆數 transition：≤ 12 筆判「突發事件（跳變）」，否則判「漸進退化（漂移）」。
- CUSUM 只是展示用的偏移能量統計，沒有門檻。

## HDBSCAN 自適應密度階梯

- 預設 (min_cluster_size, min_samples) = (25, 3)。
- 隔離區 ≥ 75 筆加試 (15, 3)；≥ 100 筆加試 (10, 2)。候選叢集仍需 ≥ 25 筆。
- 實驗二現行走 `adopt()` 自學。`output/exp2_scale_growth/2026-10-22-21-46-48/stages.csv`（commit 37ae787，seed 42，T1/8000rpm）九段的發現延遲落在 21～105 筆，最慢的是第一段 7screws（105 筆）。
- 候選群取自整個隔離區，會混入前一段的殘餘：從 2screws 段起的四段，學到的群多數都是前一段注入的配置；3screws 段的群多數是 5screws，純度 54.4%。所以發現延遲不等於該段配置自己成叢所需的筆數。
- 自適應密度階梯的消融數字只在 `confirm()` 重擬合版本量過，`adopt()` 版本還沒重做。
- 畫面顯示「已試分群 N 次」代表隔離區仍在累積、還沒成群。

## 極座標健康地圖（方向與半徑）

- 方向 = 與各已知故障「射線」的 cos 相似度，最接近的射線代表最像哪種已知故障；cos 越低方向越陌生。
- 半徑 = 偏離健康中心的距離，代表嚴重度。
- 量尺擴張後 PCA 投影會改變，前端會清空散佈圖，屬刻意行為。

## 偵測統計的讀法

- 學會前偵測率：某故障被學會之前，被判未知的比例（越高越好）。
- 學會後認出率：學會之後，被判為已知的比例；天生約 90–95%，因為閾值取第 95 百分位。

## 處置建議原則

- 系統只判「已知／未知」與「漸進／突發」，不會自動給出故障根因。實驗二自學的新類只有「模型新類 N」這個名字，對應哪種螺絲配置要人看事後對照判斷。
- 出現候選新故障時：檢查叢集大小、純度、樣本蒐集區間；蒐集區間偏舊可能是健康期誤報累積。
- 「突發事件」警報建議立即停機檢查固定件；「漸進退化」建議排程檢修並持續觀察 EWMA。
  以上處置屬本專案操作約定，現場規範以維修手冊為準。
